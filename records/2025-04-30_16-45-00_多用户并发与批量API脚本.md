## 二、后端并发控制系统实现

### 2.1 核心组件

创建了 `backend/core/concurrency.py`，包含以下关键组件：

#### GPU资源锁 (GPULock)
- **功能**: 确保同一时间只有一个TTS任务使用GPU
- **实现**: 基于 `asyncio.Lock` 的异步锁
- **特性**:
  - 超时机制（默认300秒）
  - 等待队列计数
  - 占用时长统计
  - 详细的日志记录

```python
class GPULock:
    """GPU资源锁 - 确保同一时间只有一个TTS任务使用GPU"""
    async def acquire(self, task_id: str, timeout: float = 300.0) -> bool
    def release()
```

#### 速率限制器 (RateLimiter)
- **算法**: 令牌桶算法
- **默认配置**:
  - 每分钟60个请求
  - 突发流量上限10个
  - 会话过期时间30分钟
- **特性**:
  - 自动令牌补充
  - 会话自动清理
  - 429限流响应

```python
class RateLimiter:
    """速率限制器 - 使用令牌桶算法"""
    requests_per_minute: int = 60
    burst_size: int = 10
```

#### 任务队列 (TaskQueue)
- **功能**: 管理TTS请求的执行顺序
- **实现**: 基于 `asyncio.PriorityQueue`
- **特性**:
  - 优先级支持（1-10，数字越小优先级越高）
  - 并发控制（信号量）
  - 超时处理（默认300秒）
  - 异常捕获和记录

```python
class TaskQueue:
    """异步任务队列 - 管理TTS请求的执行顺序"""
    max_concurrent: int = 1
    queue: asyncio.PriorityQueue
```

## 三、批量TTS客户端脚本

### 3.1 功能特性

创建了 `scripts/batch_tts_client.py`，具备以下功能：

1. **多格式支持**: CSV, JSON, TXT
2. **全算法支持**: 9种TTS算法
3. **并发控制**: 客户端级并发请求
4. **错误重试**: 自动重试机制（默认3次）
5. **进度显示**: tqdm进度条
6. **报告生成**: JSON + CSV格式
7. **ZIP打包**: 可选输出ZIP包

### 3.2 使用示例

```bash
# CSV格式输入
python batch_tts_client.py -i texts.csv -m chattts -o ./results

# 并发处理
python batch_tts_client.py -i texts.csv -m gptsovits -c 3 -s speaker_001

# 生成ZIP包
python batch_tts_client.py -i texts.csv -m f5tts -o ./results --zip
```

### 3.3 输入文件格式

**CSV格式**:
```csv
text,speaker_id
"欢迎使用VersTTS系统。",speaker_001
"今天天气真不错。",speaker_002
```

**JSON格式**:
```json
[
  {"text": "欢迎使用VersTTS系统。", "speaker_id": "speaker_001"},
  {"text": "今天天气真不错。", "speaker_id": "speaker_002"}
]
```

**TXT格式**:
```
欢迎使用VersTTS系统。
今天天气真不错。
```

### 3.4 输出文件

- `audio_XXXX.wav` - 生成的音频文件
- `report.json` - 详细报告
- `mapping.csv` - 文本与音频映射
- `tts_results.zip` - ZIP包（可选）
