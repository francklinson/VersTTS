## 下载工具

已创建下载/处理工具: `tools/download_reference_voices.py`

### 使用方法

#### 1. 查看可用数据集
```bash
python tools/download_reference_voices.py --list
```

#### 2. 处理下载的音频
下载公开数据集后，使用以下命令处理音频文件：

```bash
python tools/download_reference_voices.py \
  --process /path/to/downloaded/audio.wav \
  --category children \
  --name "儿童声音-01" \
  --gender female \
  --age "8-10" \
  --text "你好，这是参考音频的文本内容。"
```

参数说明:
- `--process`: 源音频文件路径
- `--category`: 分类 (children/teenagers/adults)
- `--name`: 人声名称
- `--gender`: 性别 (male/female)
- `--age`: 年龄段
- `--text`: 参考文本

### 工具功能
- ✅ 音频质量验证（时长、采样率、声道）
- ✅ 自动转换为单声道22050Hz
- ✅ 静音检测
- ✅ 自动更新metadata.json
- ✅ 生成唯一ID

## 推荐的获取流程

### 方案1: Common Voice（推荐）
1. 访问 https://commonvoice.mozilla.org/
2. 下载中文数据集（zh-CN）
3. 筛选符合以下条件的音频：
   - 儿童和青少年录音（通过年龄元数据筛选）
   - 时长5-30秒
   - 无明显背景噪声
4. 使用下载工具处理

### 方案2: THCHS-30（快速）
1. 访问 http://www.openslr.org/18/
2. 下载数据集
3. 筛选适合作为参考音频的片段
4. 使用下载工具处理

### 方案3: 自建录音（最可靠）
1. 邀请儿童和中学生参与录音
2. 录制5-10秒清晰语音
3. 获得监护人书面授权
4. 使用下载工具处理

## 质量要求

### 音频规格
- 采样率: 22050Hz
- 声道: 单声道
- 位深度: 16-bit
- 时长: 5-30秒
- 格式: WAV

### 声音质量
- ✅ 声音清晰，无明显背景噪音
- ✅ 无混响/回声
- ✅ 无背景音乐
- ✅ 无其他说话人声音
- ✅ 发音标准，语速正常
- ❌ 避免咳嗽、笑声等杂音
- ❌ 避免过度情感化的表达
