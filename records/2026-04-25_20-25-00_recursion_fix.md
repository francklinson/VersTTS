# ChatTTS 合成失败 - 递归深度超限修复

**时间戳**: 2026-04-25 20:25:00  
**问题**: 使用web录制的说话人进行语音合成时失败  
**错误信息**: `maximum recursion depth exceeded`  
**修改文件**: backend/api_server.py

## 问题分析

日志显示合成时出现递归深度超限错误：
```
2026-04-25 20:21:33 | INFO | 【ChatTTS】说话人特征加载完成 - spk_emb=None, spk_smp长度=552, txt_smp='参考音频文本'
2026-04-25 20:21:40 | ERROR | 【错误】ChatTTS合成错误 | maximum recursion depth exceeded
```

## 根本原因

`txt_smp` 参数设置不正确导致递归错误。

原代码设置：`txt_smp = "参考音频文本"`

在 ChatTTS 的 `decorate_code_prompts` 方法中：
```python
txt_smp = "" if txt_smp is None else txt_smp
if spk_emb is not None:
    text = [f"[Stts][spk_emb]{txt_smp}{i}[Ptts]" for i in text]
else:
    text = [f"[Stts][empty_spk]{txt_smp}{i}[Ptts]" for i in text]
```

当 `txt_smp` 包含中文字符时，可能导致 ChatTTS 内部处理时出现递归循环。

## 修复方案

将 `txt_smp` 从 `"参考音频文本"` 改为空字符串 `""`：

```python
# 修复前
spk_smp = chat.sample_audio_speaker(wav_numpy)
txt_smp = "参考音频文本"  # 使用固定参考文本

# 修复后
spk_smp = chat.sample_audio_speaker(wav_numpy)
txt_smp = ""  # 使用空字符串作为参考文本，避免递归问题
```

## 修改位置

文件: `backend/api_server.py`  
位置: 第 1078 行附近

## 建议

如需记录参考音频的原始文本内容，建议：
1. 在保存说话人时增加 `ref_text` 字段
2. 从数据库中读取实际的参考文本传给 `txt_smp`
3. 或者始终保持 `txt_smp=""` 也能正常工作
