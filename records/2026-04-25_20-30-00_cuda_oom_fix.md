# ChatTTS 合成失败 - GPU内存不足问题分析

**时间戳**: 2026-04-25 20:30:00  
**问题**: 使用 web 录制的说话人进行语音合成时失败  
**错误信息**: `maximum recursion depth exceeded` / `torch.OutOfMemoryError: CUDA out of memory`  
**修改文件**: backend/api_server.py

## 问题分析

日志最初显示 `maximum recursion depth exceeded`，但进一步测试发现实际上是 **GPU内存不足** 导致的错误。

测试日志显示：
```
torch.OutOfMemoryError: CUDA out of memory. Tried to allocate 20.00 MiB. 
GPU 0 has a total capacity of 23.54 GiB of which 44.44 MiB is free.
Process 49709 has 14.21 GiB memory in use.
```

## 根本原因

1. GPU 内存被之前的进程占用（14.21 GiB）
2. ChatTTS 推理需要更多内存
3. 之前的测试脚本占用了大量 GPU 内存没有释放

## 修复内容

### 1. 添加 GPU 内存清理

在推理前添加 `torch.cuda.empty_cache()`：

```python
# 清理 GPU 缓存
if torch.cuda.is_available():
    torch.cuda.empty_cache()
    gpu_mem_before = torch.cuda.memory_allocated() / 1024**3
    system_logger.info(f"【ChatTTS】GPU内存清理完成，当前使用: {gpu_mem_before:.2f}GB")
```

### 2. 添加 OOM 错误处理

添加专门的内存不足错误处理：

```python
try:
    wavs = chat.infer(
        [text],
        stream=False,
        params_infer_code=params,
    )
except RuntimeError as e:
    if "out of memory" in str(e).lower():
        system_logger.error(f"【ChatTTS】GPU内存不足: {e}")
        # 尝试清理GPU内存
        if torch.cuda.is_available():
            torch.cuda.empty_cache()
            system_logger.info(f"【ChatTTS】GPU内存已清理，请重试")
        raise HTTPException(status_code=503, detail="GPU内存不足，请稍后重试")
    raise
```

## 建议

1. **重启后端服务** 以释放被占用的 GPU 内存
2. 如果问题持续，检查是否有其他进程占用了 GPU：
   ```bash
   nvidia-smi
   ```
3. 考虑降低 batch size 或并发请求数

## 验证

通过测试脚本验证了以下场景：
1. ✅ 使用随机说话人 (`spk_emb`) 合成成功
2. ✅ 从音频提取 `spk_smp` 成功
3. ✅ 使用 `spk_smp` (设置 `skip_refine_text=True`) 合成成功
4. ✅ 使用 `spk_smp` (不设置 `skip_refine_text`) 合成成功
5. ✅ 数据库保存/读取流程正常

代码逻辑本身是正确的，问题是 GPU 内存管理。
