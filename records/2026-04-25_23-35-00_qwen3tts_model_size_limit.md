# Qwen3-TTS 根据模型大小限制前端工作模式

**时间**: 2026-04-25 23:35:00  
**任务**: 根据选择的模型大小（0.6B/1.7B）限制前端可选的工作模式  
**状态**: ✅ 已完成

---

## 1. 模型大小与功能对应关系

### 1.7B 模型（完整功能）

| 功能 | 支持情况 | 说明 |
|------|---------|------|
| 基础合成 | ✅ | 使用默认参考音频 |
| 声音克隆 | ✅ | 支持上传参考音频克隆 |
| 预设音色 | ✅ | 9种优质预设音色 |
| 预设音色+指令控制 | ✅ | 支持自然语言指令控制情感 |
| 音色设计 | ✅ | 通过自然语言描述设计音色 |

### 0.6B 模型（功能受限）

| 功能 | 支持情况 | 说明 |
|------|---------|------|
| 基础合成 | ✅ | 使用默认参考音频 |
| 声音克隆 | ✅ | 支持上传参考音频克隆 |
| 预设音色 | ✅ | 9种优质预设音色 |
| 预设音色+指令控制 | ❌ | **0.6B-CustomVoice 不支持指令控制** |
| 音色设计 | ❌ | **0.6B-VoiceDesign 模型不存在** |

---

## 2. 实现的功能限制

### 当选择 0.6B 模型时：

1. **隐藏"音色设计"选项**
   - 0.6B 没有 VoiceDesign 模型
   - 仅显示：基础合成、声音克隆、预设音色

2. **隐藏"指令控制"输入框**（在预设音色模式下）
   - 0.6B-CustomVoice 不支持指令控制
   - 仅在预设音色模式下隐藏指令控制

3. **显示功能限制提示**
   - 蓝色信息框显示 0.6B 模型的限制
   - 提示用户预设音色可用但不支持指令控制
   - 提示音色设计需要切换至 1.7B 模型

### 当选择 1.7B 模型时：

- 显示所有可用功能（取决于模型是否安装）
- 不显示 0.6B 限制提示
- 支持所有工作模式和指令控制

## 3. 修改的文件

### `frontend/app.html`

#### 新增函数

1. **`updateQwen3ModeBySize()`**
   - 根据模型大小动态更新可选的工作模式
   - 0.6B：隐藏音色设计选项
   - 1.7B：显示所有选项（受模型安装状态限制）

2. **`showQwen3SizeLimitMessage(modelSize)`**
   - 显示 0.6B 模型的功能限制提示
   - 蓝色信息框，包含具体限制说明

#### 修改函数

3. **`updateQwen3Options()`**
   - 添加模型大小判断
   - 0.6B+预设音色模式下隐藏指令控制
   - 更新指令控制标签文本（显示不支持提示）

#### 修改 HTML

4. **模型大小选择器**
   ```html
   <select id="qwen3tts-size" onchange="updateQwen3ModeBySize()">
   ```
   - 添加 `onchange` 事件监听

#### 修改调用

5. **模型状态检查回调**
   - 将 `updateQwen3TTSModeOptions()` 替换为 `updateQwen3ModeBySize()`
   - 删除旧的 `updateQwen3TTSModeOptions()` 函数
