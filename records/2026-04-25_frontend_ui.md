## 前端架构

### 技术栈
- **纯前端**: HTML5 + CSS3 + JavaScript (原生，无框架)
- **UI设计**: 响应式设计，支持桌面和移动端
- **API通信**: Fetch API

### 文件结构
```
frontend/
└── index.html          # 单页面应用，包含所有HTML/CSS/JS
```

## 前端功能

### 1. 模型选择区
- 5个TTS模型的卡片式展示
- 点击选择模型，高亮显示
- 每个模型显示图标、名称和简介

### 2. 参数配置区
各模型的专属参数面板：

**ChatTTS:**
- 温度 (0-1)
- Top P (0-1)
- Top K (1-100)

**CosyVoice:**
- 模式选择 (SFT/Zero-shot/跨语言/指令)
- 说话人选择
- 参考音频上传 (可选)
- 参考文本/指令文本

**F5-TTS:**
- 参考音频上传 (可选，默认使用内置音频)
- 参考文本 (可选)
- NFE步数
- CFG强度
- 语速

**Qwen3-TTS:**
- 模型大小 (0.6B/1.7B)
- 模式 (基础/声音克隆)
- 参考音频上传 (可选)

**OpenVoice:**
- 语言选择 (中/英文)
- 风格选择
- 语速调节
- 参考音频上传 (可选)

### 3. 文本输入区
- 多行文本输入框
- 支持中文和英文
- 支持特殊标签（如 [laughter]）

### 4. 结果展示区
- 音频播放器
- 模型标识
- 下载按钮

### 5. 状态指示
- 服务健康状态指示器
- 操作状态提示（成功/错误）
- 加载动画

## 访问地址

启动服务后，访问以下地址使用前端：

```
http://localhost:8000/app
```

或使用浏览器直接打开前端文件（仅限静态展示）。

## 使用流程

1. **选择模型**: 点击模型卡片选择要使用的TTS模型
2. **配置参数**: 根据需要调整模型参数
3. **输入文本**: 在文本框输入要合成的内容
4. **生成语音**: 点击"生成语音"按钮
5. **播放/下载**: 在结果区播放或下载生成的音频

## 前端与API交互

### API端点
```javascript
const API_BASE = window.location.origin;

// 健康检查
GET ${API_BASE}/health

// 语音合成
POST ${API_BASE}/tts/{model}
  - model: chattts, cosyvoice, f5tts, qwen3tts, openvoice
  - body: FormData
```

### 请求示例
```javascript
const formData = new FormData();
formData.append('text', '你好，这是测试。');
formData.append('temperature', '0.3');

const response = await fetch('http://localhost:8000/tts/chattts', {
    method: 'POST',
    body: formData
});

const data = await response.json();
// data.audio_url 为生成的音频文件URL
```

## 响应式设计

### 桌面端 (>= 1024px)
- 模型卡片：3列网格
- 参数区域：多列布局

### 平板端 (768px - 1023px)
- 模型卡片：2列网格
- 参数区域：2列布局

### 移动端 (< 768px)
- 模型卡片：1列堆叠
- 参数区域：单列布局

## 特色功能

1. **智能参考音频**: F5-TTS/Qwen3-TTS 无需上传参考音频即可使用
2. **实时状态**: 显示服务在线状态和操作反馈
3. **模型记忆**: 记住当前选择的模型和参数
4. **一键下载**: 生成的音频可直接下载
