# ChatTTS 合成报错修复记录

**时间**: 2026-04-26  
**问题**: ChatTTS 合成语音时报错

## 错误信息

```
【错误】ChatTTS合成错误 | cannot access local variable 'time' where it is not associated with a value
```

## 问题原因

在修复之前的 CUDA 错误时，在 `get_chattts_model()` 函数的异常处理块中添加了以下代码：

```python
except RuntimeError as e:
    if "CUDA" in str(e) or "cuda" in str(e).lower():
        # ...
        if torch.cuda.is_available():
            try:
                # ...
                import time  # 错误：重复导入
                time.sleep(1)
```

由于 `time` 模块已经在文件顶部导入（`import time` 在第 41 行），在函数内部再次 `import time` 会导致 Python 将 `time` 视为局部变量，但在赋值前就使用了它。

## 修复措施

**文件**: `backend/api_server.py`

**修改内容**: 删除 `except` 块内部的重复 `import time` 语句

```python
# 修改前
import time  # 在函数内部重复导入
time.sleep(1)

# 修改后
time.sleep(1)  # 直接使用已导入的 time 模块
```

## 经验教训

1. 不要在函数内部重复导入已在文件顶部导入的模块
2. Python 的导入机制：在函数内部使用 `import` 语句会使该名称成为局部变量
3. 修复代码时要注意变量的作用域
