# Qwen3-TTS 合成失败问题修复记录

**时间**: 2026-04-26 12:55:00  
**问题描述**: Qwen3-TTS 的合成失败了

## 问题排查过程

### 1. 错误信息分析
测试 Qwen3-TTS API 时出现错误：
```
cannot import name 'auto_docstring' from 'transformers.utils'
```

### 2. 根因分析
- Qwen3-TTS 代码依赖 `transformers==4.57.3`
- 当前环境安装的 transformers 版本不匹配
- 版本不兼容导致多个导入失败：
  - `auto_docstring`
  - `layer_type_validation`
  - `masking_utils`
  - `modeling_flash_attention_utils`
  - 等等

## 修复措施

### 1. 安装正确版本的依赖
```bash
pip install transformers==4.57.3
```

自动安装的配套依赖：
- tokenizers==0.22.2

### 2. 重启 API 服务
由于 transformers 是核心依赖库，必须重启服务才能加载新版本：
```bash
# 停止旧服务
pkill -f "uvicorn backend.api_server"

# 启动新服务
nohup python -m uvicorn backend.api_server:app --host 0.0.0.0 --port 8000 > logs/server.log 2>&1 &
```

## 验证结果

重启后测试 Qwen3-TTS API：

| 测试项目 | 结果 |
|---------|------|
| API 响应 | ✅ 200 OK |
| 音频生成 | ✅ 成功 |
| 文件大小 | ✅ 149804 bytes (146KB) |
| 文件格式 | ✅ RIFF WAVE, 16bit, mono 24000Hz |

## 版本信息

| 包名 | 原版本 | 修复后版本 |
|-----|-------|-----------|
| transformers | 4.51.3 | 4.57.3 |
| tokenizers | 0.21.4 | 0.22.2 |

## 结论

Qwen3-TTS 合成失败的问题是由于 transformers 版本不兼容导致的。通过安装 Qwen3-TTS 要求的 transformers==4.57.3 版本并重启 API 服务，问题已解决。

**注意**: 依赖版本变更后必须重启服务才能生效。
