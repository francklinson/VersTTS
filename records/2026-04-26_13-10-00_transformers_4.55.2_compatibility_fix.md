# Transformers 4.55.2 兼容性修复记录

**时间**: 2026-04-26 13:10:00

## 问题背景

- **CosyVoice**: 需要 transformers 4.51.3，在 4.57.3 下产生杂音
- **Qwen3-TTS**: 需要 transformers 4.57.3，在 4.51.3 下导入失败

## 解决方案

使用中间版本 **transformers 4.55.2**，并进行代码兼容性修复。

## 修复内容

### 1. 安装 transformers 4.55.2

```bash
pip install transformers==4.55.2
```

### 2. 修复 Qwen3-TTS 代码

**文件**: `algorithms/Qwen3-TTS/qwen_tts/core/tokenizer_12hz/modeling_qwen3_tts_tokenizer_v2.py`

修复 `check_model_inputs` 装饰器的兼容性问题：

```python
try:
    from transformers.utils.generic import check_model_inputs
    import inspect
    # Check if check_model_inputs is a simple decorator or a decorator factory
    if len(inspect.signature(check_model_inputs).parameters) == 1:
        # It's a simple decorator like @check_model_inputs
        _original_check_model_inputs = check_model_inputs
        def check_model_inputs(*args, **kwargs):
            if args and callable(args[0]):
                # Used as @check_model_inputs (without parentheses)
                return _original_check_model_inputs(args[0])
            # Used as @check_model_inputs() (with parentheses)
            return _original_check_model_inputs
except ImportError:
    # check_model_inputs is used as @check_model_inputs()
    def check_model_inputs(*args, **kwargs):
        def decorator(func):
            return func
        return decorator
```

### 3. 修复 api_server.py

**文件**: `backend/api_server.py`

修复 Qwen3-TTS 模型加载的 `dtype` 参数问题：

```python
# 兼容不同 transformers 版本
try:
    models[key] = Qwen3TTSModel.from_pretrained(
        model_path,
        device_map=device,
        torch_dtype=torch.bfloat16 if torch.cuda.is_available() else torch.float32,
        attn_implementation=attn_impl
    )
except TypeError:
    # 旧版本 transformers 使用 dtype 参数
    models[key] = Qwen3TTSModel.from_pretrained(
        model_path,
        device_map=device,
        attn_implementation=attn_impl
    )
```

## 版本兼容性说明

- **4.55.2** 同时支持 `layer_type_validation`（Qwen3-TTS 需要）和 `Qwen2ForCausalLM`（CosyVoice 需要）
- 4.55.2 中的 `check_model_inputs` 是简单装饰器（非装饰器工厂），需要适配
- 4.55.2 中的模型加载使用 `torch_dtype` 而非 `dtype`

## 结论

**transformers 4.55.2 是同时兼容 CosyVoice 和 Qwen3-TTS 的版本**。

通过少量代码适配，两个模型可以在同一环境下正常工作，无需维护多个 transformers 版本。
