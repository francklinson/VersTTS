# VersTTS 前后端联调部署记录

**时间:** 2026-04-26 21:30:00

## 部署概述
完成前端和后端的联调部署，前端使用拆分后的模块化结构，后端使用FastAPI提供API服务。

## 部署结构

### 前端目录结构
```
frontend/
├── index.html              # 首页 - 模型选择入口
├── login.html              # 登录页面
├── assets/
│   └── css/
│       └── common.css      # 公共样式
└── pages/
    ├── chattts.html        # ChatTTS页面
    ├── cosyvoice.html      # CosyVoice页面
    ├── f5tts.html          # F5-TTS页面
    ├── qwen3tts.html       # Qwen3-TTS页面
    ├── openvoice.html      # OpenVoice页面
    ├── gptsovits.html      # GPT-SoVITS页面
    ├── voxcpm.html         # VoxCPM页面
    ├── indextts.html       # IndexTTS页面
    └── fireredtts.html     # FireRedTTS2页面
```

### 后端服务
- **框架**: FastAPI + Uvicorn
- **端口**: 8000
- **静态文件**: 挂载frontend目录
- **CORS**: 允许所有来源

## 联调配置

### 1. 前端配置
- 所有页面使用 `window.location.origin` 作为API基础路径
- 自动适配后端服务的域名和端口
- 添加了登录状态检查

### 2. 后端配置
```python
# 静态文件挂载
frontend_dir = os.path.join(PROJECT_ROOT, "frontend")
app.mount("/", StaticFiles(directory=frontend_dir, html=True), name="frontend")

# CORS配置
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 3. 登录系统
- **默认用户名**: admin
- **默认密码**: tp123456
- **登录验证**: localStorage存储认证状态
- **未登录跳转**: 自动跳转到login.html

## 后端API

### 健康检查
```
GET /health
Response: {"status": "healthy", "timestamp": "...", "version": "1.0.0"}
```

### TTS生成
```
POST /api/tts
Content-Type: application/json

Request:
{
    "model": "chattts",
    "text": "要转换的文本",
    ...其他参数
}

Response:
{
    "success": true,
    "audio_url": "/audio/xxx.wav",
    "message": "生成成功"
}
```

### 获取音频
```
GET /audio/{filename}
Response: 音频文件流
```

## 注意事项

1. **登录状态**: 所有页面（除登录页）都需要先登录才能访问
2. **GPU需求**: TTS生成需要NVIDIA GPU支持
3. **模型加载**: 首次访问某个模型页面时可能需要加载模型
4. **文件上传**: 支持参考音频上传用于声音克隆
