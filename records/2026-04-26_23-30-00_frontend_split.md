# 前端文件拆分工作记录

**时间:** 2026-04-26 23:30:00

## 任务概述
将原有的单文件app.html（176KB）拆分为独立的模块，每个TTS方案一个独立页面。

## 拆分前状态
- 原文件: `frontend/app.html` - 176KB，约2644行
- 问题: 所有9个TTS模型代码混合在一起，维护困难

## 拆分后结构

### 新目录结构
```
frontend_split/
├── index.html              # 主页面 - 模型选择入口
├── assets/
│   └── css/
│       └── common.css      # 公共样式文件 (12KB)
└── pages/
    ├── chattts.html        # ChatTTS页面
    ├── cosyvoice.html      # CosyVoice页面
    ├── f5tts.html          # F5-TTS页面
    ├── qwen3tts.html       # Qwen3-TTS页面
    ├── openvoice.html      # OpenVoice页面
    ├── gptsovits.html      # GPT-SoVITS页面
    ├── voxcpm.html         # VoxCPM页面 (新增)
    ├── indextts.html       # IndexTTS页面 (新增)
    └── fireredtts.html     # FireRedTTS2页面 (新增)
```

## 拆分内容

### 1. 主页面 (index.html)
- 9个模型选择卡片
- 动态背景效果（声波、粒子、浮动音符）
- 用户信息显示
- 服务器健康状态检查
- 点击卡片跳转到对应模型页面

### 2. 公共样式 (common.css)
- 动态背景动画（声波、声波圈、浮动音符、粒子）
- 通用UI组件样式（按钮、输入框、卡片等）
- 响应式设计
- 模型主题色定义

### 3. 各模型页面特点

| 模型 | 特色功能 |
|------|----------|
| ChatTTS | 情感标签控制、音色选择、语速调节 |
| CosyVoice | 音色选择、语速、音调调节 |
| F5-TTS | 参考音频上传、跨语言克隆 |
| Qwen3-TTS | 基础TTS、情感选择 |
| OpenVoice | 参考音频、多风格选择、跨语言支持 |
| GPT-SoVITS | 说话人选择、参考音频、TopK/TopP参数 |
| VoxCPM | 4种模式（基础/声音设计/可控克隆/极致克隆）、CFG值、推理步数 |
| IndexTTS | 2种模式（自由/时长控制）、情感描述 |
| FireRedTTS2 | 多说话人管理、对话文本输入、流式生成 |

## 动态效果

### 已添加的动画效果
1. **底部声波条** - 20个动态高度的条形，模拟音波效果
2. **圆形声波扩散** - 5个同心圆向外扩散动画
3. **浮动音符** - 8个音符随机浮动上升
4. **粒子效果** - 10个粒子从底部向上漂浮
5. **按钮闪光** - 生成按钮的渐变光效
6. **卡片悬停** - 卡片悬停时的上浮和阴影效果

## 改进点

1. **代码可维护性**: 每个模型独立文件，修改互不影响
2. **加载性能**: 只加载当前需要的页面资源
3. **功能专一**: 每个页面针对特定模型优化界面
4. **扩展性**: 新增模型只需添加新页面
5. **缓存优化**: 公共CSS可独立缓存
