### 8. CosyVoice声音克隆功能修复

**时间:** 23:00-00:00  
**状态:** ✅ 完成

**问题:** 选择参考人声进行声音克隆时合成失败

**错误信息:**
```
Invalid file: tensor([[0., 0., 0., ..., 0., 0., 0.]])
```

**根本原因:**
1. `inference_zero_shot()` 内部会再次调用 `load_wav()`
2. 后端API传递了已经加载的tensor而不是文件路径
3. 导致内部重复加载时数据异常

**解决方案:**
直接传递音频文件路径，让 `inference_zero_shot()` 内部自己加载：

```python
# 修复前（错误）
prompt_speech = load_wav(audio_path, 16000)
model_output = cosyvoice.inference_zero_shot(text, ref_text, prompt_speech)

# 修复后（正确）
model_output = cosyvoice.inference_zero_shot(text, ref_text, audio_path)
```

**修改内容:**
1. 新增 `clone_speaker_id` 参数支持，直接读取本地音频文件
2. 前端传递说话人ID，后端直接读取 speakers 目录下的音频
3. 与 Qwen3-TTS 的说话人应用方式保持一致

**修改文件:**
- `backend/api_server.py`: API参数和处理逻辑
- `frontend/app.html`: 前端表单提交逻辑
