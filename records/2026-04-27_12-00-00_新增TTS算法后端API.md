# 新增TTS算法后端API构建记录

**日期**: 2026-04-27

## 工作概述

为 VoxCPM、IndexTTS 和 FireRedTTS2 三个TTS算法构建后端API服务，使其可以通过统一的API接口进行语音合成。

## 完成的API端点

| API端点 | 描述 | 支持模式 |
|---------|------|---------|
| `/tts/voxcpm` | VoxCPM语音合成 | base, voice_design, clone, ultimate_clone |
| `/tts/indextts` | IndexTTS语音合成 | free, controlled |
| `/tts/fireredtts` | FireRedTTS2语音合成 | clone, random |

## 后端API实现详情

### 1. VoxCPM API (`/tts/voxcpm`)

**请求参数**:
- `text` (required): 生成文本
- `mode`: 模式 (base/voice_design/clone/ultimate_clone)
- `ref_audio`: 参考音频文件 (clone/ultimate_clone模式)
- `ref_text`: 参考文本 (ultimate_clone模式)
- `voice_design_prompt`: 音色描述 (voice_design模式)
- `cfg_value`: CFG值 (默认2.0)
- `inference_timesteps`: 推理步数 (默认10)

**模型加载函数**: `get_voxcpm_model()`
- 从 `algorithms/VoxCPM/src` 导入 VoxCPM
- 加载路径: `algorithms/VoxCPM/models/VoxCPM2` 或 HuggingFace `openbmb/VoxCPM2`

### 2. IndexTTS API (`/tts/indextts`)

**请求参数**:
- `text` (required): 生成文本
- `mode`: 模式 (free/controlled)
- `prompt_wav`: 参考音频文件 (controlled模式可选)
- `emotion_text`: 情感描述文本 (controlled模式可选)
- `duration_tokens`: 时长控制token数 (controlled模式可选)

**模型加载函数**: `get_indextts_model()`
- 从 `algorithms/IndexTTS` 导入 IndexTTS
- 加载路径: `algorithms/IndexTTS/checkpoints`

### 3. FireRedTTS2 API (`/tts/fireredtts`)

**请求参数**:
- `text` (required): 生成文本
- `mode`: 模式 (clone/random)
- `ref_audio`: 参考音频文件 (clone模式)
- `ref_text`: 参考文本 (clone模式可选)
- `temperature`: 温度 (默认0.9)
- `topk`: Top K采样 (默认30)

**模型加载函数**: `get_fireredtts2_model()`
- 从 `algorithms/FireRedTTS2` 导入 FireRedTTS2
- 加载路径: `algorithms/FireRedTTS2/pretrained_models/FireRedTTS2`

## 数据模型

在 `backend/api_server.py` 中添加了三个请求数据模型：

```python
class VoxCPMRequest(BaseTTSRequest):
    mode: str = "base"
    voice_design_prompt: Optional[str] = None
    ref_audio_path: Optional[str] = None
    ref_text: Optional[str] = None
    cfg_value: float = 2.0
    inference_timesteps: int = 10

class IndexTTSRequest(BaseTTSRequest):
    prompt_wav: Optional[str] = None
    emotion_text: Optional[str] = None
    duration_tokens: Optional[int] = None
    mode: str = "free"

class FireRedTTS2Request(BaseTTSRequest):
    mode: str = "clone"
    text_list: Optional[str] = None
    prompt_wav_list: Optional[str] = None
    prompt_text_list: Optional[str] = None
    temperature: float = 0.9
    topk: int = 30
```

## API使用示例

### VoxCPM - 基础生成
```bash
curl -X POST "http://localhost:8000/tts/voxcpm" \
  -F "text=你好，这是VoxCPM生成的语音" \
  -F "mode=base"
```

### IndexTTS - 可控生成
```bash
curl -X POST "http://localhost:8000/tts/indextts" \
  -F "text=你好，这是IndexTTS生成的语音" \
  -F "mode=controlled" \
  -F "emotion_text=开心地说"
```

### FireRedTTS2 - 声音克隆
```bash
curl -X POST "http://localhost:8000/tts/fireredtts" \
  -F "text=你好，这是FireRedTTS2生成的语音" \
  -F "mode=clone" \
  -F "ref_audio=@/path/to/reference.wav"
```

## 注意事项

1. 这三个算法需要相应的模型文件才能正常工作
2. 首次调用会触发模型加载，可能需要较长时间
3. 所有API都支持 `output_format` 参数 (url/base64)
4. 参考音频格式建议使用WAV，采样率48kHz
