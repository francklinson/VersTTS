# 服务启动修复记录

**日期**: 2026-04-27

## 问题描述

服务启动失败，执行 `bash start_server.sh restart` 后出现错误：
```
[✗] 服务启动失败 - 进程已退出
```

## 错误排查

查看日志发现 Python 导入错误：
```
File "/home/zhouchenghao/PycharmProjects/VersTTS/backend/api_server.py", line 773
    "/tts/f5tts",
IndentationError: unexpected indent
```

## 问题原因

在 `backend/api_server.py` 文件的第 773-782 行存在残留的缩进代码：

```python
# ==================== API路由 ====================
            "/tts/f5tts",
            "/tts/qwen3tts",
            "/tts/openvoice",
            "/tts/gptsovits",
            "/tts/batch/create",
            "/tts/batch/{job_id}/status",
            "/tts/batch/{job_id}/process",
            "/tts/batch/{job_id}/download",
        ]
    }

@app.get("/health")
```

这些代码看起来像是之前编辑时留下的垃圾代码，导致 Python 语法错误。

## 修复措施

删除第 773-782 行的残留代码：

```python
# ==================== API路由 ====================

@app.get("/health")
```
