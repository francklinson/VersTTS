### 2. 声音克隆卡住/很慢
**状态**: ✅ 已修复

**问题描述**:
选择说话人后进行声音克隆，生成速度很慢或卡住。

**原因分析**:
Qwen3-TTS 的声音克隆有两种模式：
- `x_vector_only_mode=True`: 只使用说话人嵌入，不需要参考文本
- `x_vector_only_mode=False` (ICL模式): 需要参考文本才能工作

当说话人没有保存参考文本时，如果 `x_vector_only_mode=False`，会抛出错误并卡住。

**修复方案**:
在 `backend/api_server.py` 中添加自动检测逻辑：
```python
# 如果没有参考文本，强制使用 x_vector_only_mode=True
if not ref_text_to_use and not x_vector_only_mode:
    logger.info(f"说话人没有参考文本，自动切换到 x_vector_only_mode=True")
    effective_x_vector_mode = True
```

**建议**: 为了获得更好的克隆效果，建议在"说话人管理"中为每个说话人添加参考文本。

### 3. 预设音色生成不正确
**状态**: ✅ 已修复

**问题描述**:
使用 CustomVoice 模型进行预设音色生成时，生成的音频音色不正确（如选择女声却生成男声）。

**根本原因**:
1. **Speaker 名称大小写不匹配**: 配置文件中 speaker 名称是纯小写（如 `ono_anna`），前端传递的是首字母大写（如 `Ono_Anna`）
2. **语言参数不正确**: CustomVoice 模型应该使用 `language="Chinese"` 而不是 `language="Auto"`

**修复方案**:

1. 前端修改 (`frontend/pages/qwen3tts.html`):
```html
<!-- 修改前 -->
<div class="speaker-card" data-speaker="Ono_Anna">Ono_Anna<br><small>女声</small></div>

<!-- 修改后 -->
<div class="speaker-card" data-speaker="ono_anna">Ono Anna<br><small>女声</small></div>
```

2. 后端修改 (`backend/api_server.py`):
```python
# 修改前
language="Auto"

# 修改后
language="Chinese"
```

### 5. 指令控制不生效
**状态**: ✅ 已说明

**问题描述**:
用户询问指令控制是否生效。

**分析结果**:
| 模式 | 模型类型 | 指令控制 | 说明 |
|-----|---------|---------|------|
| voice_clone | Base | ❌ 不支持 | 只克隆音色，无法控制风格 |
| custom_voice | CustomVoice | ✅ 支持 | 但 0.6B 模型不支持 |
| voice_design | VoiceDesign | ✅ 支持 | 通过描述设计音色 |

**实现**:
- 0.6B 模型：隐藏指令控制区域
- 1.7B 模型：显示指令控制区域
