## 关键修复 - 接近原始GitHub代码

### 1. IndexTTS → IndexTTS2 (重要修复)

**问题**: 原来使用的是旧的 `IndexTTS` (infer.py)，与模型不匹配

**解决**: 切换到 `IndexTTS2` (infer_v2.py)，与GitHub README完全一致

**代码变更**:
```python
# 原来 (错误)
from indextts.infer import IndexTTS
tts = IndexTTS(cfg_path=cfg_path, model_dir=model_dir, device=device)

# 现在 (正确，与GitHub一致)
from indextts.infer_v2 import IndexTTS2
tts = IndexTTS2(
    cfg_path="checkpoints/config.yaml",
    model_dir="checkpoints",
    use_fp16=False,
    device=device,
    use_cuda_kernel=False,
    use_deepspeed=False
)
```

**调用方式** (与GitHub README示例一致):
```python
tts.infer(
    spk_audio_prompt='voice.wav',
    text=text,
    output_path="gen.wav",
    verbose=True
)
```

**注意**: IndexTTS2 **必须**提供参考音频 (`spk_audio_prompt`)，这是官方设计的要求

---

### 2. FireRedTTS2 音频保存修复

**问题**: 使用 `soundfile.write()` 保存音频格式不被识别

**解决**: 使用 `torchaudio.save()`，与GitHub示例完全一致

**代码变更**:
```python
# 原来 (错误)
sf.write(audio_path, audio_data, samplerate=sr)

# 现在 (正确，与GitHub一致)
torchaudio.save(audio_path, audio.cpu(), 24000)
```

**调用方式** (与GitHub README示例一致):
```python
# 随机音色
audio = fireredtts2.generate_monologue(text=text, temperature=0.9, topk=30)
torchaudio.save("output.wav", audio.cpu(), 24000)

# 声音克隆
audio = fireredtts2.generate_monologue(
    text=text,
    prompt_wav="reference.wav",
    prompt_text="参考文本",
    temperature=0.9,
    topk=30
)
torchaudio.save("output.wav", audio.cpu(), 24000)
```
