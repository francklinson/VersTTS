## API变更详情

### 请求参数

**POST /tts/openvoice**

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| text | string | 是 | 要合成的文本 |
| clone_speaker_id | string | 否* | 说话人ID（优先使用） |
| ref_wav | file | 否* | 参考音频文件 |
| style | string | 否 | 音色风格，默认 default |
| speed | float | 否 | 语速，默认 1.0 |
| language | string | 否 | 语言，默认 zh |

*注: clone_speaker_id 和 ref_wav 至少提供一个

## 与说话人管理模块的集成

改造后的 OpenVoice 与说话人管理模块的工作流程：

1. 用户在 **说话人管理模块** 中添加/录制说话人
2. 说话人音频保存在 `speakers/` 目录
3. 说话人信息存储在 `speakers/speakers_db.json`
4. OpenVoice 页面加载时从 `/speakers` API 获取列表
5. 用户选择说话人后，发送 `clone_speaker_id` 到后端
6. 后端从说话人音频提取音色嵌入，用于语音克隆
