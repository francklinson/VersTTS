# OpenVoice V2 版本升级

## 时间戳
2026-04-28 22:45:00

## 升级内容

### 1. 后端修改 (backend/api_server.py)
- `get_openvoice_models()` 函数新增 `use_v2` 参数
- 默认使用 V2 版本：V1 TTS 模型 + V2 Converter + V2 音色嵌入
- V2 版本的音色嵌入路径：`checkpoints_v2/checkpoints_v2/base_speakers/ses/`

### 2. 前端修改 (frontend/pages/openvoice.html)
- 页面标题更新为 "OpenVoice V2"
- 副标题更新强调 V2 版本更好的音质

### V2 版本架构
```
V1 TTS 模型（基础语音合成）
    ↓
V2 Converter（音色转换）
    ↓
V2 音色嵌入（中文/英文等）
```

### V2 版本支持的音色嵌入
- `zh.pth` - 中文音色
- `en-default.pth` - 英文默认音色
- `en-us.pth` - 美式英文
- `en-br.pth` - 英式英文
- `en-au.pth` - 澳洲英文
- `en-india.pth` - 印度英文
- `es.pth` - 西班牙文
- `fr.pth` - 法文
- `jp.pth` - 日文
- `kr.pth` - 韩文

## 重启服务
修改完成后需要重启后端服务才能生效。
