### 1. 后端API改造 (backend/api_server.py)

**修改内容**:
- 在 `/tts/f5tts` 端点添加 `clone_speaker_id` 参数
- 实现三种音频获取方式的优先级：
  1. **优先方式**: 通过 `clone_speaker_id` 从说话人管理模块获取音频和参考文本
  2. **兼容方式**: 使用上传的参考音频（已废弃，保留向后兼容）
  3. **默认方式**: 使用内置的默认参考音频（根据语言自动选择中文或英文）

**关键代码变更**:
```python
# 新增参数
clone_speaker_id: Optional[str] = Form(None)

# 优先使用clone_speaker_id从说话人管理模块获取音频
if clone_speaker_id:
    db = load_speakers_db()
    speaker = None
    for s in db.get("speakers", []):
        if s["id"] == clone_speaker_id:
            speaker = s
            break
    
    if not speaker:
        raise HTTPException(status_code=404, detail=f"说话人不存在: {clone_speaker_id}")
    
    ref_path = speaker.get("audio_path")
    use_ref_text = ref_text or speaker.get("reference_text", "")
```

## 实现细节

### 后端API逻辑
1. 接收 `clone_speaker_id` 参数
2. 从 `speakers_db.json` 中查找对应说话人
3. 验证说话人音频文件是否存在
4. 获取说话人的 `reference_text` 作为参考文本
5. 使用 `f5tts.infer()` 进行语音合成

### 前端交互流程
1. 页面加载时从 `/speakers` 接口获取说话人列表
2. 渲染下拉框选择器
3. 用户选择说话人后显示详细信息
4. 点击生成按钮发送 `clone_speaker_id` 和生成文本
5. 接收并播放生成的音频
