# F5-TTS 模块路径修复

**时间**: 2026-04-28 23:20:00

## 问题描述
F5-TTS 合成失败，报错 `No module named 'f5_tts.api'`

## 原因分析
`sys.path` 配置错误，只添加了 `algorithms/F5-TTS` 目录，但 `f5_tts` 模块实际位于 `algorithms/F5-TTS/src/` 下。

## 修复方案

### 修改文件: backend/api_server.py

```python
# 修改前 (第234行)
sys.path.insert(0, os.path.join(PROJECT_ROOT, 'algorithms', 'F5-TTS'))

# 修改后
sys.path.insert(0, os.path.join(PROJECT_ROOT, 'algorithms', 'F5-TTS', 'src'))
```

## 目录结构验证

```
algorithms/F5-TTS/
├── src/
│   └── f5_tts/
│       ├── api.py          # <- 目标文件
│       ├── model/
│       ├── infer/
│       └── configs/
└── checkpoints/
```

## 后续操作
需要重启后端服务使修改生效。
