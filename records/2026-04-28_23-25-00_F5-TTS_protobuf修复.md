# F5-TTS Protobuf 版本修复

**时间**: 2026-04-28 23:25:00

## 问题描述
F5-TTS 合成失败，报错：`cannot import name 'builder' from 'google.protobuf.internal'`

## 原因分析
protobuf 版本 3.19.6 太旧，缺少 `builder` 模块。需要升级到 4.x 版本。

## 修复方案

```bash
pip install protobuf==4.25.3
```

## 依赖冲突说明
升级后出现以下依赖冲突警告：
- `google-api-core` 要求 protobuf>=4.25.8
- `descript-audiotools` 要求 protobuf<3.20
- `proto-plus` 要求 protobuf>=4.25.8
- `googleapis-common-protos` 要求 protobuf>=4.25.8

但 F5-TTS 需要 protobuf 4.x 才能正常工作。

## 建议
如果后续测试发现问题，可以尝试安装 protobuf 4.25.8：
```bash
pip install protobuf==4.25.8
```
