# F5-TTS 与 GPT-SoVITS 模块冲突修复

**时间**: 2026-04-28 23:30:00

## 问题描述
F5-TTS 合成失败，报错：`cannot import name 'CFM' from 'f5_tts.model'`，但错误指向的路径是 GPT-SoVITS 的 f5_tts 模块。

## 原因分析

两个项目都有 `f5_tts` 模块：
- F5-TTS: `algorithms/F5-TTS/src/f5_tts/`
- GPT-SoVITS: `algorithms/GPT-SoVITS/GPT_SoVITS/f5_tts/`

`sys.path.insert(0, ...)` 会把路径插到列表最前面，导致**后插入的路径优先级更高**。

原来的顺序：
```python
sys.path.insert(0, 'F5-TTS/src')           # 第1个插入，实际在列表靠后
sys.path.insert(0, 'GPT-SoVITS')           # 第2个插入
sys.path.insert(0, 'GPT-SoVITS/GPT_SoVITS') # 第3个插入，在最前面
```

Python 导入 `f5_tts` 时，优先找到 GPT-SoVITS 的模块。

## 修复方案

将 F5-TTS 的路径移到最后插入，确保它排在 `sys.path` 最前面：

```python
# 修改前
sys.path.insert(0, os.path.join(PROJECT_ROOT, 'algorithms', 'F5-TTS', 'src'))
# ... 其他路径 ...
sys.path.insert(0, os.path.join(PROJECT_ROOT, 'algorithms', 'GPT-SoVITS', 'GPT_SoVITS'))

# 修改后
# ... 其他路径 ...
sys.path.insert(0, os.path.join(PROJECT_ROOT, 'algorithms', 'GPT-SoVITS', 'GPT_SoVITS'))
# F5-TTS 路径必须最后插入，确保 f5_tts 模块优先从 F5-TTS 项目加载
sys.path.insert(0, os.path.join(PROJECT_ROOT, 'algorithms', 'F5-TTS', 'src'))
```
