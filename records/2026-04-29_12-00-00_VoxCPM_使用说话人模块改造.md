### 1. VoxCPM 算法分析

#### 实现原理
VoxCPM是一个**无tokenizer**的文本转语音(TTS)系统，采用端到端的**扩散自回归架构**，直接生成连续语音表示，绕过了传统的离散tokenization步骤。

**技术架构：**
- **MiniCPM-4 主干网络**: 基于2B参数的大语言模型
- **AudioVAE V2**: 非对称编解码设计，支持16kHz输入和48kHz输出
- **扩散自回归生成**: 结合扩散模型和自回归生成的优势
- **流匹配(Flow Matching)**: 用于高质量音频合成

**核心创新：**
- 无Tokenizer设计：直接生成连续表示，避免离散化带来的信息损失
- 上下文感知合成：自动从文本内容推断适当的韵律和表达
- 内置超分辨率：无需外部上采样器即可输出48kHz音频

#### 可用版本
| 版本 | 参数 | 特点 | 推荐场景 |
|------|------|------|----------|
| VoxCPM2 | 2B | 最新版本，30语言，48kHz输出 | 生产环境 |
| VoxCPM1.5 | - | SFT & LoRA微调支持 | 自定义训练 |
| VoxCPM-0.5B | 0.5B | 轻量级版本 | 资源受限环境 |

#### 模型大小
- **VoxCPM2**: 2B参数，约8GB显存需求
- **VoxCPM1.5**: 约6GB显存需求
- **VoxCPM-0.5B**: 约5GB显存需求

#### 支持的功能
1. **文本转语音 (TTS)** - 支持30种语言输入
2. **声音设计 (Voice Design)** - 通过自然语言描述创建全新音色
3. **可控声音克隆 (Controllable Cloning)** - 从短参考音频克隆音色
4. **极致克隆 (Ultimate Cloning)** - 提供参考音频和转录文本进行最高相似度克隆
5. **实时流式生成** - RTF低至~0.3 (NVIDIA RTX 4090)

#### 性能优劣
**优势：**
- 支持30种语言
- 48kHz高音质输出
- 无Tokenizer设计避免信息损失
- 支持流式生成

**劣势：**
- 2B模型需要较大显存(建议16GB+)
- 推理速度相比轻量级模型较慢
- 某些低资源语言效果可能不如高资源语言

### 2. 前端页面修改

**修改文件：** `frontend/pages/voxcpm.html`

**主要改动：**
1. **声音克隆模式 (clone)**：
   - 移除了参考音频文件上传输入框
   - 添加了说话人选择下拉框 (`speakerSelectClone`)
   - 添加了说话人信息显示区域
   - 添加了无说话人警告提示

2. **极致克隆模式 (ultimate_clone)**：
   - 移除了参考音频文件上传输入框
   - 移除了参考文本输入框
   - 添加了说话人选择下拉框 (`speakerSelectUltimate`)
   - 添加了参考文本自动显示区域（从说话人信息中读取）
   - 添加了无说话人警告提示

3. **JavaScript逻辑更新**：
   - 添加了`loadSpeakers()`函数加载说话人列表
   - 添加了`renderSpeakerSelects()`函数渲染下拉框
   - 添加了`onSpeakerChange()`函数处理说话人选择变化
   - 更新了`generateTTS()`函数，使用`clone_speaker_id`参数

### 3. 后端API修改

**修改文件：** `backend/api_server.py`

**主要改动：**
1. **API参数更新**：
   - 添加了`clone_speaker_id`参数用于接收说话人ID

2. **逻辑更新**：
   - 优先使用`clone_speaker_id`获取说话人信息和音频路径
   - 兼容旧版：如果直接上传了参考音频，仍然可以处理
   - clone模式：使用`reference_wav_path`参数
   - ultimate_clone模式：使用`prompt_wav_path`和`prompt_text`参数，其中`prompt_text`从说话人管理模块中获取

3. **错误处理**：
   - 如果说话人不存在返回404错误
   - 如果极致克隆模式缺少参考文本，退化为声音克隆模式并发出警告

4. **资源清理**：
   - 只清理临时上传的文件，不删除说话人管理模块中的音频文件

## API调用示例

### 基础生成
```bash
curl -X POST http://localhost:8000/tts/voxcpm \
  -F "text=你好，这是VoxCPM的演示。" \
  -F "mode=base" \
  -F "cfg_value=2.0" \
  -F "inference_timesteps=10"
```

### 使用说话人克隆
```bash
curl -X POST http://localhost:8000/tts/voxcpm \
  -F "text=使用选中说话人的声音生成这段文本。" \
  -F "mode=clone" \
  -F "clone_speaker_id=spk_1777133375796" \
  -F "cfg_value=2.0" \
  -F "inference_timesteps=10"
```

### 极致克隆
```bash
curl -X POST http://localhost:8000/tts/voxcpm \
  -F "text=这是极致克隆的演示。" \
  -F "mode=ultimate_clone" \
  -F "clone_speaker_id=spk_1777133375796" \
  -F "cfg_value=2.0" \
  -F "inference_timesteps=10"
```
