## 1. 项目分析总结

### 1.1 项目基本信息
- **项目名称**: IndexTTS / IndexTTS2
- **项目地址**: https://github.com/index-tts/index-tts
- **开发团队**: 哔哩哔哩 (Bilibili)
- **当前版本**: IndexTTS-2.0

### 1.2 核心架构
IndexTTS2是一个**自回归零样本TTS模型**，主要特点：

1. **技术架构**:
   - 自回归Transformer（GPT风格）
   - BigVGAN声码器
   - 情感-音色解耦设计
   - S2MEL模块（语义到梅尔频谱）

2. **核心创新**:
   - 首个支持精确时长控制的自回归零样本TTS
   - 情感特征和说话人特征解耦
   - 基于Qwen3微调的软指令情感控制机制
   - 三阶段训练范式提升稳定性

### 1.3 支持的工作模式

| 模式 | 说明 | 必需参数 | 可选参数 |
|------|------|----------|----------|
| **free（自由生成）** | 自回归生成，复现参考音频韵律 | spk_audio_prompt | - |
| **controlled（可控生成）** | 支持情感控制 | spk_audio_prompt | emotion_text |

**注意**: 时长控制功能（duration_tokens）在IndexTTS2当前发布版本中尚未启用

## 3. 后端API改造

### 3.1 API端点
- **端点**: `POST /tts/indextts`
- **位置**: `backend/api_server.py`

### 3.2 请求参数

```python
{
    "text": str,              # 必需 - 要合成的文本
    "mode": str,              # 可选 - "free"或"controlled"
    "clone_speaker_id": str,  # 可选 - 说话人ID（优先使用）
    "prompt_wav": File,       # 可选 - 参考音频文件（备用）
    "emotion_text": str,      # 可选 - 情感描述文本
    "duration_tokens": int,   # 可选 - 时长控制（暂不支持）
    "output_format": str      # 可选 - "url"或"base64"
}
```

### 3.3 主要修改内容

1. **添加clone_speaker_id参数支持**:
   - 优先从说话人管理模块获取参考音频
   - 支持通过说话人ID自动获取音频路径

2. **情感控制支持**:
   - 当提供emotion_text时，自动设置use_emo_text=True
   - 使用推荐的emo_alpha=0.6参数

3. **音频采样率修正**:
   - IndexTTS2输出采样率为22050Hz（不是24000Hz）

### 3.4 代码变更
```python
# 修改前: 只支持prompt_wav上传
# 修改后: 支持clone_speaker_id优先，prompt_wav作为备用

if clone_speaker_id:
    # 从说话人管理模块获取音频
    speaker = get_speaker_by_id(clone_speaker_id)
    ref_path = speaker["audio_path"]
elif prompt_wav:
    # 保存上传的参考音频
    ref_path = save_upload_file(prompt_wav)
```

## 6. 使用方法

### 6.1 基础使用（自由生成）
```python
from indextts.infer_v2 import IndexTTS2

tts = IndexTTS2(
    cfg_path="checkpoints/config.yaml",
    model_dir="checkpoints",
    use_fp16=False,
    use_cuda_kernel=False
)

tts.infer(
    spk_audio_prompt="reference.wav",
    text="你好，这是IndexTTS的语音合成演示。",
    output_path="output.wav",
    verbose=True
)
```

### 6.2 情感控制（可控生成）
```python
tts.infer(
    spk_audio_prompt="reference.wav",
    text="今天真是太开心了！",
    output_path="output.wav",
    use_emo_text=True,
    emo_text="非常开心地",  # 情感描述
    emo_alpha=0.6,
    verbose=True
)
```

## 7. 已知限制

1. **推理速度**: 自回归生成相对较慢
2. **内存需求**: 需要较大显存（建议16GB+）
3. **流式支持**: 当前版本不支持流式生成
4. **时长控制**: IndexTTS2论文中提到的时长控制功能在当前发布版本中尚未启用
5. **情感描述**: 依赖Qwen3模型，可能需要尝试不同描述才能获得最佳效果
