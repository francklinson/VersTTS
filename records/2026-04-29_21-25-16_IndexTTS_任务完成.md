## 2. 遇到的问题及解决方案

### 2.1 前端说话人列表为空

**现象**: 页面加载后说话人选择下拉框为空

**原因**: 
- `switchMode` 函数使用了全局 `event` 对象，在现代浏览器中不可用
- 函数名与 `common.js` 中的全局常量冲突
- 模式切换时会清除 `selectedSpeakerId`

**解决**:
```javascript
// 修改前: onclick="switchMode('free')"
// 修改后: onclick="onSwitchMode(event, 'free')"

// 函数定义修改为接收 event 参数
function onSwitchMode(event, mode) {
    // ... 不再清除 selectedSpeakerId
}
```

### 2.2 clone_speaker_id 参数未传递

**现象**: 后端报错 "IndexTTS2需要提供参考音频"

**原因**: 
- 代码已修改但后端服务未重新加载
- `onSwitchMode` 函数在切换模式时清除了 `selectedSpeakerId`

**解决**:
- 重启后端服务加载新代码
- 修改 `onSwitchMode` 不再清除选择状态
- 同步两个模式下的选择器

### 2.3 transformers 版本兼容性错误

**现象**: `'GenerationConfig' object has no attribute 'forced_decoder_ids'`

**原因**: IndexTTS 代码针对旧版 transformers 编写，新版中 `forced_decoder_ids` 属性可能被移除

**解决**:
```python
# 修改前
if generation_config.forced_decoder_ids is not None:

# 修改后
forced_decoder_ids = getattr(generation_config, 'forced_decoder_ids', None)
if forced_decoder_ids is not None:
```

### 2.4 前端文案错误

**现象**: 页面显示 "网秦Index - 精确时长控制TTS"

**解决**: 修正为 "哔哩哔哩 IndexTTS - 精确时长控制TTS"
