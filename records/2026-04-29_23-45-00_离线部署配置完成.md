### 2. 创建离线部署环境变量配置文件

创建文件: `.env.offline`

配置了以下关键环境变量：
- `HF_HUB_OFFLINE=1`: 禁用 HuggingFace Hub 在线访问
- `HF_DATASETS_OFFLINE=1`: 禁用 HuggingFace Datasets 在线访问
- `TRANSFORMERS_OFFLINE=1`: 禁用 Transformers 在线下载
- `HF_HUB_DISABLE_DOWNLOADS=1`: 禁止 HuggingFace 下载
- `HF_HOME`: 设置本地缓存目录
- `TRANSFORMERS_CACHE`: 设置 Transformers 缓存目录
- `TORCH_HOME`: 设置 PyTorch Hub 缓存目录

### 3. 修改启动脚本支持离线模式

修改文件: `start_server.sh`

新增功能：
- 添加 `--offline` 参数支持
- 在离线模式下自动加载 `.env.offline` 环境变量

### 4. 修改后端 API 支持离线模式

修改文件: `backend/api_server.py`

改动内容：
- 在导入 transformers 等库之前设置离线环境变量
- 检测离线模式并打印日志
- VoxCPM 模型加载增加 `local_files_only` 参数支持

代码示例：
```python
# 检查是否启用离线模式
if os.environ.get('TRANSFORMERS_OFFLINE') == '1' or os.environ.get('HF_HUB_OFFLINE') == '1':
    print("[离线部署] 检测到离线模式环境变量，禁用HuggingFace在线访问")
    os.environ['HF_HUB_OFFLINE'] = '1'
    os.environ['TRANSFORMERS_OFFLINE'] = '1'
    os.environ['HF_HUB_DISABLE_DOWNLOADS'] = '1'

# VoxCPM 离线加载
models["voxcpm"] = VoxCPM.from_pretrained(
    model_path, 
    load_denoiser=False,
    local_files_only=is_offline  # 离线模式下强制使用本地文件
)
```

## 离线部署使用说明

### 快速开始

1. **准备模型文件**
   ```bash
   # 在有网络的环境中下载所有模型
   # 参考 OFFLINE_DEPLOYMENT.md 中的各算法下载指南
   ```

2. **打包传输到目标服务器**
   ```bash
   tar -czvf verstts_models.tar.gz algorithms/*/models ...
   scp verstts_models.tar.gz user@target-server:/path/
   ```

3. **在目标服务器解压**
   ```bash
   cd /path/to/VersTTS
   tar -xzvf verstts_models.tar.gz
   ```

4. **验证模型完整性**
   ```bash
   python check_models.py
   ```

5. **离线模式启动服务**
   ```bash
   ./start_server.sh start --offline
   ```
