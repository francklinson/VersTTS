## 3. 执行内容

### 3.1 创建模型检查脚本

**文件:** `scripts/check_models.py`

功能：
- 检查所有9个TTS算法的模型文件是否完整
- 计算模型目录大小
- 检测HuggingFace缓存状态
- 支持 `--fix` 参数自动创建缺失目录

### 3.2 创建模型下载脚本

**文件:** `scripts/download_models.py`

功能：
- 支持从 HuggingFace/ModelScope/Wget 下载模型
- 支持批量下载 `--all`
- 支持单个模型下载
- 支持列出可下载模型 `--list`
- 总下载大小预估: 50-80GB

### 3.3 更新离线部署配置

**文件:** `.env.offline`

主要配置项：
```bash
# HuggingFace 离线模式
export HF_HUB_OFFLINE=1
export HF_DATASETS_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
export HF_HUB_DISABLE_DOWNLOADS=1

# 本地缓存路径
export HF_HOME="${VERTTS_ROOT}/models/hf_cache"
export TRANSFORMERS_CACHE="${VERTTS_ROOT}/models/transformers_cache"
export MODELSCOPE_CACHE="${VERTTS_ROOT}/models/modelscope_cache"
export TORCH_HOME="${VERTTS_ROOT}/models/torch_cache"

# 各算法模型路径
export CHATTTS_MODEL_PATH="${VERTTS_ROOT}/algorithms/ChatTTS/models"
export COSYVOICE_MODEL_PATH="${VERTTS_ROOT}/algorithms/CosyVoice/models"
export F5TTS_MODEL_PATH="${VERTTS_ROOT}/algorithms/F5-TTS/models"
export GPTSOVITS_MODEL_PATH="${VERTTS_ROOT}/algorithms/GPT-SoVITS/GPT_SoVITS/pretrained_models"
export OPENVOICE_V1_PATH="${VERTTS_ROOT}/algorithms/OpenVoice/checkpoints_v1"
export OPENVOICE_V2_PATH="${VERTTS_ROOT}/algorithms/OpenVoice/checkpoints_v2"
export QWEN3TTS_MODEL_PATH="${VERTTS_ROOT}/algorithms/Qwen3-TTS/models"
export VOXCPM_MODEL_PATH="${VERTTS_ROOT}/algorithms/VoxCPM/models"
export INDEXTTS_MODEL_PATH="${VERTTS_ROOT}/algorithms/IndexTTS/checkpoints"
export FIREREDTTS_MODEL_PATH="${VERTTS_ROOT}/algorithms/FireRedTTS2/pretrained_models"
```

### 3.4 验证模型路径统一

各算法模型统一按以下规则存放：
- 主模型: `algorithms/<算法名>/models/`
- 检查点: `algorithms/<算法名>/checkpoints/` 或 `pretrained_models/`
- HF缓存: `models/hf_cache/`
- 其他缓存: `models/{transformers_cache,torch_cache,datasets_cache}/`

## 4. 使用说明

### 4.1 模型下载（联网环境）

```bash
# 下载所有必需模型
python scripts/download_models.py --all

# 下载单个模型
python scripts/download_models.py --chattts

# 列出可下载模型
python scripts/download_models.py --list
```

### 4.2 模型检查

```bash
# 检查模型完整性
python scripts/check_models.py

# 创建缺失目录
python scripts/check_models.py --fix
```

### 4.3 离线部署启动

```bash
# 方式1: 使用 --offline 参数
./start_server.sh start --offline

# 方式2: 手动加载环境变量
source .env.offline
./start_server.sh start
```
