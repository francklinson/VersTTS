# 优化删除说话人弹窗

## 修改时间
2026-05-07 11:00:00

## 修改内容

### 1. 添加自定义删除确认弹窗 (speaker_modal.html)

**新增弹窗结构**:
```html
<div id="deleteConfirmModal" class="modal-overlay" style="z-index: 2000;">
    <div class="modal-content" style="max-width: 400px; text-align: center; padding: 30px;">
        <div class="delete-icon" style="font-size: 48px; margin-bottom: 15px;">🗑️</div>
        <h3 style="color: #dc2626; margin-bottom: 10px; font-size: 1.25rem;">确认删除</h3>
        <p id="deleteConfirmText">...</p>
        <div class="delete-actions">
            <button class="btn-secondary" onclick="closeDeleteConfirm()">取消</button>
            <button class="btn-danger" onclick="confirmDelete()">确认删除</button>
        </div>
    </div>
</div>
```

**弹窗特点**:
- 红色主题色，醒目提示
- 居中显示，尺寸适中
- 显示说话人名称
- 提示"此操作不可撤销"

### 2. 更新删除逻辑 (speaker.js)

**新增函数**:

1. **`showDeleteConfirm(speakerId)`** - 显示删除确认弹窗
   - 存储待删除的说话人ID
   - 动态更新弹窗文本，显示说话人名称
   - 添加弹窗显示动画

2. **`closeDeleteConfirm()`** - 关闭删除确认弹窗
   - 添加关闭动画效果
   - 清除待删除的说话人ID

3. **`confirmDelete()`** - 确认删除操作
   - 执行实际的删除请求
   - 关闭弹窗并刷新列表

**修改函数**:

4. **`deleteSpeaker(speakerId)`** - 简化为显示确认弹窗

**事件监听增强**:
- ESC键优先关闭删除确认弹窗
- 点击遮罩层关闭删除确认弹窗

### 3. 添加样式 (common.css)

**新增样式**:

1. **弹窗容器样式**
   - 红色主题阴影效果
   - 顶部红色渐变条
   - 圆角边框

2. **图标动画**
   ```css
   @keyframes shakeIcon {
       0%, 100% { transform: rotate(0deg); }
       25% { transform: rotate(-10deg); }
       75% { transform: rotate(10deg); }
   }
   ```
   - 垃圾桶图标摇摆动画

3. **按钮效果**
   - 危险按钮：红色渐变背景，悬停阴影
   - 取消按钮：悬停背景变化
   - 按钮点击波纹效果

4. **进入动画**
   ```css
   @keyframes deleteModalSlideIn {
       from { opacity: 0; transform: scale(0.9) translateY(20px); }
       to { opacity: 1; transform: scale(1) translateY(0); }
   }
   ```

5. **遮罩层效果**
   - 更深的背景色 (rgba(0, 0, 0, 0.7))
   - 更强的模糊效果 (blur(8px))

## 技术说明

**弹窗位置优化**:
- 将删除确认弹窗从 speakerModal 内部移至与 speakerModal 平级
- 这样弹窗可以显示在整个页面中央，而不是仅在说话人管理模态框内
- z-index 设置为 2000，确保在最上层显示

## 交互说明

1. 点击删除按钮 → 显示确认弹窗
2. 点击"确认删除" → 执行删除并关闭弹窗
3. 点击"取消" → 关闭弹窗，不执行删除
4. 点击遮罩层 → 关闭弹窗
5. 按ESC键 → 关闭弹窗
