#### 1.2 transformers 版本冲突

**问题**: Qwen3-TTS 需要 `transformers==4.57.3`，OmniVoice 需要 `transformers>=5.3.0`

**尝试的方案**:
1. ❌ 全局升级 transformers 到 5.x：导致 Qwen3-TTS/VoxCPM 等全部失败
2. ❌ 运行时切换 transformers 版本：PyTorch 模型对象保留了 transformers 5.x 的内部状态，切换回 4.x 后不兼容
3. ✅ **独立服务架构**：OmniVoice 运行在独立进程（端口 8001），使用 `lib/transformers5/` 目录下的 transformers 5.6.2

#### 1.3 独立服务架构

**文件**:
- `lib/transformers5/` - 独立 transformers 5.6.2 安装目录
- `omnivoice_service.py` - OmniVoice 独立服务脚本
- `backend/engines/omnivoice_engine.py` - 简化为通过 HTTP 调用独立服务
- `backend/routers/tts/omnivoice.py` - 主服务路由，通过 HTTP 调用独立服务

**架构**:
```
主服务 (端口 8000)     OmniVoice 独立服务 (端口 8001)
transformers 4.57.3    transformers 5.6.2 (lib/transformers5/)
  ├─ Qwen3-TTS           ├─ OmniVoice 模型加载
  ├─ VoxCPM              ├─ TTS 合成
  ├─ OpenVoice           └─ HTTP API (/tts, /health)
  └─ ...其他 TTS 引擎
```

**启动方式**:
```bash
# 启动主服务
bash start_server.sh start --port 8000 --offline

# 启动 OmniVoice 独立服务
nohup python omnivoice_service.py > logs/omnivoice_service.log 2>&1 &
```
