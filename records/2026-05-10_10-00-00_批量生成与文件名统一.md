## 一、音频文件名格式统一

### 1.1 问题描述
Qwen3-TTS、CosyVoice、ChatTTS、F5-TTS通过 `save_temp_audio` 函数保存音频，生成固定格式 `tts_{timestamp}.wav`，而其他TTS路由（GPT-SoVITS、VoxCPM等）使用 `{model}_{timestamp}.wav` 格式，导致文件名不统一。

### 1.2 解决方案
修改 `backend/core/audio_utils.py` 的 `save_temp_audio` 函数，添加 `prefix` 参数：

```python
def save_temp_audio(audio_data: np.ndarray, sample_rate: int, 
                    suffix: str = ".wav", normalize: bool = True,
                    prefix: str = "tts") -> str:
    """保存临时音频文件
    
    Args:
        prefix: 文件名前缀，默认"tts"
    """
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S_%f")
    temp_path = os.path.join(OUTPUTS_DIR, f"{prefix}_{timestamp}{suffix}")
```

### 1.3 更新TTS路由
更新以下路由，传入相应的模型名称前缀：

| TTS模型 | 文件名格式 | 修改文件 |
|---------|-----------|----------|
| Qwen3-TTS | qwen3tts_{timestamp}.wav | backend/routers/tts/qwen3tts.py |
| CosyVoice | cosyvoice_{timestamp}.wav | backend/routers/tts/cosyvoice.py |
| ChatTTS | chattts_{timestamp}.wav | backend/routers/tts/chattts.py |
| F5-TTS | f5tts_{timestamp}.wav | backend/routers/tts/f5tts.py |

其他TTS路由已在各自文件中实现统一格式：
- GPT-SoVITS: `gptsovits_{timestamp}.wav`
- VoxCPM: `voxcpm_{timestamp}.wav`
- IndexTTS: `indextts_{timestamp}.wav`
- FireRedTTS2: `fireredtts_{timestamp}.wav`
- OpenVoice: `openvoice_{timestamp}.wav`
- OmniVoice: `omnivoice_{timestamp}.wav`

## 二、批量生成（抽卡）功能

### 2.1 功能概述
支持一次生成多个音频变体（2-20个），用户可以：
- 预览所有生成的音频
- 选择最满意的结果
- 单个下载或批量打包下载

### 2.2 后端API实现

#### 2.2.1 数据模型 (backend/models/schemas.py)
```python
class BatchGenerateRequest(BaseModel):
    """批量生成（抽卡）请求"""
    text: str = Field(..., description="要合成的文本")
    model: str = Field(default="voxcpm", description="TTS模型名称")
    mode: str = Field(default="base", description="生成模式")
    count: int = Field(default=10, ge=2, le=20, description="生成数量(2-20)")
    speaker_id: Optional[str] = Field(default=None, description="说话人ID")
    voice_design_prompt: Optional[str] = Field(default=None)
    control_prompt: Optional[str] = Field(default=None)

class BatchGenerateResponse(BaseModel):
    """批量生成（抽卡）响应"""
    success: bool
    message: str
    model: str
    count: int
    audio_urls: List[str]
    audio_files: List[str]
```

#### 2.2.2 批量生成API (backend/routers/batch.py)
- **端点**: `POST /tts/batch/generate`
- **支持模型**: VoxCPM, Qwen3-TTS
- **功能**: 
  - 根据参数批量生成多个音频
  - 每次生成使用相同的文本和参数，但模型内部采样不同，产生变体
  - 返回所有音频的URL列表和文件名列表

#### 2.2.3 批量下载API (backend/routers/batch.py)
- **端点**: `POST /tts/batch/download-zip`
- **参数**:
  - `files`: 音频文件名列表
  - `zip_name`: ZIP包名称（可选）
- **功能**: 将选中的音频文件打包成ZIP并返回

## 四、API使用示例

### 批量生成请求
```bash
curl -X POST "http://localhost:8000/tts/batch/generate" \
  -F "text=你好，这是测试文本" \
  -F "model=voxcpm" \
  -F "mode=base" \
  -F "count=10"
```

### 批量下载请求
```bash
curl -X POST "http://localhost:8000/tts/batch/download-zip" \
  -F "files=voxcpm_20260510_100000_123456.wav" \
  -F "files=voxcpm_20260510_100001_234567.wav" \
  -F "zip_name=my_batch.zip" \
  --output my_batch.zip
```
