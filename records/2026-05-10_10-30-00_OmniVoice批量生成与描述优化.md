## 一、OmniVoice批量生成功能

### 1.1 后端实现

在 `backend/routers/batch.py` 中添加OmniVoice批量生成功能：

```python
async def _batch_generate_omnivoice(text: str, mode: str, count: int,
                                    speaker_id: str = None,
                                    voice_design_prompt: str = None) -> Dict:
    """批量生成OmniVoice音频"""
```

**功能特点**:
- 通过调用OmniVoice独立服务接口进行批量生成
- 支持三种模式：
  - `auto_voice`: 随机音色
  - `voice_clone`: 声音克隆（使用说话人管理模块中的音频）
  - `voice_design`: 声音设计（通过属性描述创建音色）
- 生成的音频统一保存到 outputs 目录
- 使用 `omnivoice_{timestamp}.wav` 文件名格式
- 每次生成后清理临时文件

### 1.2 前端实现

更新 `frontend/pages/omnivoice.html`，添加完整的批量生成功能：

**新增UI组件**:
1. **批量生成数量设置**: 可设置2-20个生成数量
2. **双按钮设计**: 
   - "生成语音" - 单条生成
   - "批量生成" - 批量生成
3. **进度条**: 显示生成进度
4. **批量结果展示**: 网格布局展示所有生成结果
5. **选择功能**:
   - 每个结果可单独选择/取消
   - 全选/取消全选按钮
   - 显示已选择数量
6. **下载功能**:
   - 单个音频下载
   - 选中音频批量打包下载

**支持的批量生成模式**:
- 随机音色模式 (`auto_voice`): 使用随机音色生成多个音频变体
- 声音克隆模式 (`voice_clone`): 基于选择的说话人克隆多个音频变体
- 声音设计模式 (`voice_design`): 基于声音属性描述生成多个音频变体

## 五、API使用示例

### OmniVoice批量生成请求
```bash
curl -X POST "http://localhost:8000/tts/batch/generate" \
  -F "text=你好，这是测试文本" \
  -F "model=omnivoice" \
  -F "mode=voice_design" \
  -F "count=10" \
  -F "voice_design_prompt=男，四川话，高音调"
```

### 批量下载请求
```bash
curl -X POST "http://localhost:8000/tts/batch/download-zip" \
  -F "files=omnivoice_20260510_103000_123456.wav" \
  -F "files=omnivoice_20260510_103001_234567.wav" \
  -F "zip_name=my_batch.zip" \
  --output my_batch.zip
```
