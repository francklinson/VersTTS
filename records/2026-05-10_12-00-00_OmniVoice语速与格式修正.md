## 一、语速限制

### 1.1 问题描述
前端设置了语速范围 `min="0.5" max="2.0"`，但后端没有验证，用户可能通过API直接传入非法值。

### 1.2 解决方案
在 `backend/routers/tts/omnivoice.py` 添加后端校验：

```python
# 语速参数校验
if speed < 0.5 or speed > 2.0:
    raise HTTPException(
        status_code=400,
        detail=f"语速参数必须在 0.5-2.0 之间，当前值: {speed}"
    )
```

### 1.3 限制范围
- **最小值**: 0.5（慢速，0.5倍速）
- **最大值**: 2.0（快速，2倍速）
- **默认值**: 1.0（正常速度）

## 二、声音设计格式修正

### 2.1 问题描述
用户输入声音设计属性时，可能出现缺少逗号分隔的情况：
- ❌ 错误: `宁夏话女，中年，高音调`（"宁夏话"和"女"之间缺少逗号）
- ❌ 错误: `男中年，高音调`（"男"和"中年"之间缺少逗号）
- ❌ 错误: `四川话, 男 , 高音调`（使用英文逗号，有多余空格）

### 2.2 解决方案
新增 `_fix_voice_design_format()` 函数，自动修正格式：

```python
def _fix_voice_design_format(prompt: str) -> str:
    """修正声音设计属性的格式"""
    
    # 1. 处理方言和性别之间缺少分隔符
    # 例如："宁夏话女" -> "宁夏话，女"
    for dialect in ['四川话', '东北话', '宁夏话', ...]:
        for gender in ['男', '女']:
            result = re.sub(f'{dialect}{gender}', f'{dialect}，{gender}', result)
    
    # 2. 处理性别和年龄之间缺少分隔符
    # 例如："男中年" -> "男，中年"
    for gender in ['男', '女']:
        for age in ['儿童', '少年', '青年', '中年', '老年']:
            result = re.sub(f'{gender}{age}', f'{gender}，{age}', result)
    
    # 3. 规范化分隔符
    result = result.replace(',', '，')        # 英文逗号转中文
    result = re.sub(r'\s*，\s*', '，', result)  # 去除逗号前后空格
    result = re.sub(r'，+', '，', result)      # 多个逗号合并
    
    return result.strip()
```

### 2.3 修正示例

| 输入 | 输出 | 说明 |
|------|------|------|
| `宁夏话女，中年，高音调` | `宁夏话，女，中年，高音调` | 添加方言和性别之间的逗号 |
| `男中年，高音调` | `男，中年，高音调` | 添加性别和年龄之间的逗号 |
| `四川话, 男 , 高音调` | `四川话，男，高音调` | 统一使用中文逗号，去除空格 |
| `四川话，，男` | `四川话，男` | 合并多个逗号 |

## 五、问题修复（2026-05-10 12:30 补充）

### 5.1 新发现问题
点击属性标签时，属性之间仍然可能粘连：
- ❌ 错误: `女，老年甘肃话，极高音调`（"老年"和"甘肃话"之间缺少逗号）

### 5.2 根因分析
`removeAttributeValue` 函数使用正则 `，?value(，)?` 移除属性时，会同时删除前后的逗号，导致相邻属性粘连。

### 5.3 修复方案

**前端修复** (`frontend/pages/omnivoice.html`):
```javascript
function removeAttributeValue(value) {
    // 优先匹配 "属性，" 模式，保留前面属性的逗号
    if (current.includes(value + '，')) {
        current = current.replace(value + '，', '');
    } else if (current.includes('，' + value)) {
        // 再匹配 "，属性" 模式
        current = current.replace('，' + value, '');
    }
    // 清理多余逗号
    current = current.replace(/，+/g, '，');
    current = current.replace(/^，|，$/g, '');
}
```

**后端增强** (`omnivoice.py` 和 `batch.py`):
- 添加迭代处理（最多10次），处理多重粘连
- 增加6种属性组合的处理：
  1. 方言 + 性别（宁夏话女）
  2. 性别 + 年龄（男中年）
  3. 年龄 + 方言（老年甘肃话）⭐ 新增
  4. 年龄 + 音调（老年高音调）⭐ 新增
  5. 性别 + 音调（男高音调）⭐ 新增
  6. 方言 + 音调（四川话高音调）⭐ 新增
- 添加 `(?![\u4e00-\u9fff])` 负向先行断言，避免误匹配
