# CosyVoice 独立服务部署完成

## 完成时间
2026-05-10 13:00:00

## 任务背景
CosyVoice 需要 transformers==4.51.3 版本，而主项目使用的是 transformers 4.57.3。为了解决这个问题，参考 OmniVoice 的独立服务方案，为 CosyVoice 部署了单独的 transformers 服务环境。

## 完成内容

### 1. 创建 transformers4 目录并安装依赖
- 目录: `lib/transformers4/`
- 安装版本: transformers==4.51.3
- 同时安装: huggingface-hub, filelock, pyyaml, regex, requests, tokenizers, safetensors, tqdm, fsspec, packaging, numpy

### 2. 创建 CosyVoice 独立服务脚本
- 文件: `cosyvoice_service.py`
- 端口: 8002 (可配置)
- 功能:
  - 使用 transformers 4.51.3 运行
  - 支持 zero_shot 模式 (声音克隆)
  - 支持 instruct 模式 (指令控制)
  - 提供 `/health` 健康检查端点
  - 提供 `/tts` TTS 合成端点
  - 显存自动清理

### 3. 修改后端路由
- 文件: `backend/routers/tts/cosyvoice.py`
- 修改内容:
  - 不再直接导入 CosyVoice 模型
  - 通过 HTTP 请求调用独立服务
  - 支持说话人管理模块集成
  - 支持上传音频文件和说话人选择

### 4. 更新配置文件
- 文件: `backend/config.py`
- 添加配置:
  - COSYVOICE_HOST (默认: 127.0.0.1)
  - COSYVOICE_PORT (默认: 8002)

### 5. 更新服务管理脚本
- 文件: `start_server.sh`
- 新增命令:
  - `start-cosyvoice` - 启动 CosyVoice 服务
  - `stop-cosyvoice` - 停止 CosyVoice 服务
  - `restart-cosyvoice` - 重启 CosyVoice 服务
  - `status-cosyvoice` - 查看 CosyVoice 服务状态
- 主服务启动时自动启动 CosyVoice 服务
- 主服务停止时自动停止 CosyVoice 服务

## 技术架构

```
主服务 (端口 8000)
    ├── OmniVoice 服务 (端口 8001, transformers 5.x)
    └── CosyVoice 服务 (端口 8002, transformers 4.51.3)
```

## 使用方式

### 启动 CosyVoice 独立服务
```bash
./start_server.sh start-cosyvoice
```

### 停止 CosyVoice 独立服务
```bash
./start_server.sh stop-cosyvoice
```

### 查看 CosyVoice 服务状态
```bash
./start_server.sh status-cosyvoice
```

### 启动全部服务（自动启动 CosyVoice）
```bash
./start_server.sh start
```

## 验证方式

### 1. 检查服务是否运行
```bash
curl http://127.0.0.1:8002/health
```

### 2. 测试 TTS API
```bash
curl -X POST http://127.0.0.1:8002/tts \
  -F "text=你好，这是测试文本" \
  -F "mode=zero_shot" \
  -F "prompt_wav_path=/path/to/reference.wav"
```

## 注意事项

1. transformers4 目录不能删除，否则 CosyVoice 服务无法启动
2. CosyVoice 模型加载可能需要较长时间（首次启动）
3. 确保端口 8002 未被占用
4. 服务启动时会自动检查 transformers4 目录是否存在

## 相关文件

- `cosyvoice_service.py` - CosyVoice 独立服务主程序
- `lib/transformers4/` - transformers 4.51.3 依赖目录
- `backend/routers/tts/cosyvoice.py` - 后端路由（调用独立服务）
- `backend/config.py` - 配置文件
- `start_server.sh` - 服务管理脚本
