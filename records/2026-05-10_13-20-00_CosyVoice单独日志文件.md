# CosyVoice 服务添加单独日志文件

## 完成时间
2026-05-10 13:20:00

## 任务背景
用户希望 CosyVoice 独立服务有单独的日志文件，方便排查问题和监控服务运行状态。

## 完成内容

### 1. 修改 CosyVoice 服务脚本
- 文件: `cosyvoice_service.py`
- 添加内容:
  - 日志目录创建: `logs/` (如果不存在)
  - 日志文件路径: `logs/cosyvoice_service.log`
  - 使用 `RotatingFileHandler` 实现日志轮转
    - 单个文件最大: 10MB
    - 备份文件数量: 3个
  - 日志格式与主项目保持一致

### 2. 日志格式
```
%(asctime)s | %(levelname)-8s | %(message)s
```
示例:
```
2026-05-10 13:20:00 | INFO     | 【服务启动】地址: 127.0.0.1:8002
2026-05-10 13:20:05 | INFO     | 【模型加载】路径: /path/to/models/CosyVoice
2026-05-10 13:20:30 | INFO     | 【模型加载】完成 | 耗时: 25.3s
```

### 3. 日志输出位置
- **文件**: `logs/cosyvoice_service.log`
- **控制台**: stdout (同时输出，方便查看)

### 4. 记录的日志内容
- 服务启动/停止
- 模型加载过程 (含耗时)
- TTS 请求信息 (模式、文本预览)
- 错误信息和堆栈跟踪
- GPU 缓存清理

## 查看日志

### 实时查看
```bash
tail -f logs/cosyvoice_service.log
```

### 查看最近100行
```bash
tail -n 100 logs/cosyvoice_service.log
```

### 查看日志轮转文件
```bash
ls -la logs/cosyvoice_service.log*
# cosyvoice_service.log      (当前日志)
# cosyvoice_service.log.1    (上一个备份)
# cosyvoice_service.log.2    (更早的备份)
# cosyvoice_service.log.3    (最早的备份)
```
