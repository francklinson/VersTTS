# 修复批量下载ZIP接口400错误

**时间**: 2026-05-23 10:50:00

**问题**: `/tts/batch/download-zip` 接口返回 400 Bad Request 错误

---

## 问题分析

后端API使用 `List[str] = Form(...)` 来接收文件列表参数，但 FastAPI 对表单数组的处理有特定要求。当前端使用 `FormData.append('files', filename)` 多次添加文件时，FastAPI 的 `List[str]` 无法正确解析这种格式，导致返回 400 错误。

## 解决方案

修改 `backend/routers/batch.py` 中的 `batch_download_zip` 函数，使用 `Request` 对象手动解析表单数据：

```python
# 修改前
@router.post("/download-zip")
async def batch_download_zip(files: List[str] = Form(...), zip_name: str = Form(None)):
    ...
    if len(files) > 50:
        raise HTTPException(status_code=400, detail="单次下载文件数量不能超过50个")

# 修改后
@router.post("/download-zip")
async def batch_download_zip(request: Request, zip_name: str = Form(None)):
    ...
    # 从表单数据中获取文件列表
    form_data = await request.form()
    files = []
    for key in form_data.keys():
        if key == 'files':
            value = form_data.getlist(key)
            if value:
                files.extend(value)
    
    if len(files) > 100:
        raise HTTPException(status_code=400, detail="单次下载文件数量不能超过100个")
```

## 修改内容

1. **参数接收方式**: 从 `List[str] = Form(...)` 改为使用 `Request` 对象手动解析
2. **文件数量限制**: 从 50 个提升到 100 个（与批量生成最大值保持一致）
3. **表单解析**: 使用 `form_data.getlist('files')` 正确获取所有文件参数

## 影响范围

- **接口**: `/tts/batch/download-zip`
- **前端页面**: VoxCPM、Qwen3-TTS、OmniVoice、CosyVoice 的批量下载功能
- **功能**: 批量选择音频后打包下载为ZIP

## 测试建议

1. 在前端进行批量生成（如生成5个音频）
2. 选择其中几个音频，点击"下载选中"
3. 验证ZIP包是否能正常下载
4. 测试选择超过50个文件时的限制提示
