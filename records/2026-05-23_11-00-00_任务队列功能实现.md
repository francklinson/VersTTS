# 任务队列功能实现

**时间**: 2026-05-23 11:00:00

**任务**: 增加任务队列，支持多用户后台排队、异步执行、任务记录和文件下载

---

## 功能概述

实现了完整的任务队列系统，用户可以将TTS生成任务提交到后台队列，无需等待生成完成即可继续其他操作。生成完成后可在任务记录页面下载音频文件。

---

## 后端实现

### 1. 任务队列核心模块

**文件**: `backend/task_queue.py`

核心功能：
- `TaskRecord` 数据类：存储任务信息（ID、用户、模型、状态、结果等）
- `TaskQueue` 类：任务队列管理器
  - 优先级队列支持（数字越小优先级越高）
  - 后台异步执行器（单线程，避免GPU资源冲突）
  - 任务状态管理（queued/processing/completed/failed/cancelled）
  - 任务记录持久化（JSON文件存储）
  - 自动加载历史任务

```python
# 提交任务
task = await task_queue.submit_task(
    user_id=user_id,
    model="voxcpm",
    mode="base",
    text="要合成的文本",
    params={"speaker_id": "xxx"},
    priority=0
)
```

### 2. 任务处理器

**文件**: `backend/task_handlers.py`

为各TTS模型注册处理器：
- VoxCPM: `handle_voxcpm_task`
- Qwen3-TTS: `handle_qwen3tts_task`
- OmniVoice: `handle_omnivoice_task`
- CosyVoice: `handle_cosyvoice_task`

### 3. 任务队列API

**文件**: `backend/routers/task_queue.py`

API端点：

| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/tasks/submit` | 提交任务到队列 |
| GET | `/tasks/list` | 获取用户任务列表 |
| GET | `/tasks/{task_id}/status` | 查询任务状态 |
| GET | `/tasks/{task_id}/download` | 下载任务结果音频 |
| POST | `/tasks/{task_id}/cancel` | 取消等待中的任务 |
| GET | `/tasks/queue/status` | 获取队列整体状态 |
| DELETE | `/tasks/cleanup` | 清理旧任务记录 |

## 前端实现

### 1. 任务队列管理页面

**文件**: `frontend/pages/tasks.html`

功能特性：
- 任务列表展示（带状态颜色标识）
- 状态筛选器（全部/等待中/执行中/已完成/失败/已取消）
- 实时统计卡片（等待中/执行中/已完成/失败）
- 自动刷新开关（每3秒自动刷新）
- 任务结果下载按钮
- 取消任务按钮（仅等待中任务）
- 进度条显示（执行中任务）

### 2. TTS页面集成

已为所有前端可用的TTS页面集成任务队列功能，点击"生成语音"按钮将自动加入队列：

**VoxCPM** (`frontend/pages/voxcpm.html`)
- "生成语音"按钮点击后自动加入队列
- `addToQueue()` JavaScript函数
- 支持参数：speaker_id, voice_design_prompt, control_prompt

**Qwen3-TTS** (`frontend/pages/qwen3tts.html`)
- "生成语音"按钮点击后自动加入队列
- `addToQueue()` JavaScript函数
- 支持参数：speaker, speaker_id, voice_design_prompt, instruct_text

**OmniVoice** (`frontend/pages/omnivoice.html`)
- "生成语音"按钮点击后自动加入队列
- `addToQueue()` JavaScript函数
- 支持参数：speaker_id, voice_design_prompt, speed

**CosyVoice** (`frontend/pages/cosyvoice.html`)
- "生成语音"按钮点击后自动加入队列
- `addToQueue()` JavaScript函数
- 支持参数：speaker_id (根据模式选择)

### 3. 首页入口

**文件**: `frontend/index.html`

在顶部操作栏添加"任务队列"按钮，与"说话人管理"并列。

## 使用流程

1. **提交任务**：
   - 在TTS页面输入文本、选择参数
   - 点击"生成语音"按钮
   - 任务自动加入队列，页面立即响应不阻塞

2. **查看任务**：
   - 点击顶部"任务队列"按钮
   - 或在TTS页面点击"查看任务队列"链接

3. **下载结果**：
   - 任务完成后状态变为"已完成"
   - 点击"下载音频"按钮获取文件

---

## 技术特点

1. **异步执行**：任务在后台线程执行，不阻塞前端
2. **优先级队列**：支持任务优先级设置
3. **持久化存储**：任务记录保存到磁盘，服务重启不丢失
4. **用户隔离**：基于客户端IP区分用户，只能看到自己的任务
5. **状态实时**：前端自动轮询更新任务状态
