# 任务队列功能补充完善

**时间**: 2026-05-23 12:00:00

## 问题分析

现有任务队列功能虽已具备基本框架，但存在以下不完善之处：

1. **优先级队列实现缺陷** - 使用 `asyncio.Queue` 本身不支持优先级排序，无法保证高优先级任务优先执行
2. **缺少定时清理机制** - 仅在手动调用管理 API 时清理旧任务，无法自动释放磁盘空间
3. **缺少任务删除 API** - 只能取消任务，无法删除已完成/失败/已取消的任务记录
4. **缺少任务重试功能** - 失败任务无法一键重新提交
5. **缺少批量提交 API** - 无法一次性提交多个任务到队列
6. **前端缺少批量操作** - 任务队列页面没有清理、重试、删除等功能
7. **首页缺少任务提示** - 无法直观看到等待/执行中的任务数量

## 补充实现内容

### 1. 修复优先级队列实现

**文件**: `backend/task_queue.py`

- 将 `asyncio.Queue` 替换为手动维护的 `_pending_list` 列表
- 实现 `_add_pending_task()` 方法：添加任务时自动按优先级排序（数字越小优先级越高，相同优先级按创建时间先后）
- 实现 `_pop_next_task()` 方法：弹出优先级最高的任务
- 使用 `asyncio.Event` 替代队列的阻塞获取，实现高效的等待/唤醒机制
- 在 `_worker_loop` 中增加对已取消任务的跳过逻辑

### 2. 添加定时清理机制

**文件**: `backend/task_queue.py`

- 新增 `start_cleanup_scheduler()` 方法：启动后台异步定时任务
- 清理间隔：24小时
- 清理策略：删除7天前的任务记录及关联音频文件
- 在 `start()` 中自动启动定时清理
- 在 `stop()` 中优雅关闭清理任务

### 3. 添加显存释放机制

**文件**: `backend/task_queue.py`

- 在 `_execute_task` 的 `finally` 块中添加显存清理
- 执行 `gc.collect()`、`torch.cuda.empty_cache()`、`torch.cuda.synchronize()`
- 防止任务队列长时间运行导致显存泄漏

### 4. 添加任务删除 API

**文件**: `backend/task_queue.py`, `backend/routers/task_queue.py`

- 新增 `TaskQueue.delete_task()` 方法
  - 从等待列表中移除（如果任务还在等待中）
  - 拒绝删除正在执行中的任务
  - 删除任务记录 JSON 文件
  - 删除关联的音频文件
  - 从内存中移除
- 新增 `DELETE /tasks/{task_id}` API 端点

### 5. 添加任务重试 API

**文件**: `backend/routers/task_queue.py`

- 新增 `POST /tasks/{task_id}/retry` API 端点
- 仅允许重试失败或已取消的任务
- 使用原任务的参数重新提交到新任务
- 返回新旧任务ID映射

### 6. 添加批量提交 API

**文件**: `backend/routers/task_queue.py`

- 新增 `BatchTaskSubmitRequest` / `BatchTaskSubmitResponse` 数据模型
- 新增 `POST /tasks/batch/submit` API 端点
- 支持通过 JSON 字符串一次性提交多个任务
- 单个任务失败不影响其他任务
- 返回成功提交的任务ID列表和失败计数

### 7. 前端任务队列页面增强

**文件**: `frontend/pages/tasks.html`

- 增加"已取消"状态统计卡片（共5个统计项）
- 调整统计栏 grid 布局为 5 列
- 为失败/已取消任务添加"重试"按钮
- 为已完成/失败/已取消任务添加"删除"按钮
- 添加"清理已完成"批量删除按钮（自动显示/隐藏）
- 实现 `retryTask()` 函数：调用重试 API
- 实现 `deleteTask()` 函数：调用删除 API
- 实现 `batchDeleteCompleted()` 函数：批量清理已完成/失败/已取消的任务
- 为新增按钮添加 CSS 样式

### 8. 首页任务队列红点提示

**文件**: `frontend/index.html`

- 在"任务队列"按钮上添加红点徽章（`queue-badge`）
- 添加红点动画效果（pulse 动画）
- 实现 `updateTaskQueueBadge()` 函数：
  - 调用 `/tasks/list` API 获取任务列表
  - 统计等待中 + 执行中的任务数量
  - 数量大于0时显示红点，否则隐藏
  - 数量超过99显示"99+"
- 页面加载时立即获取一次，之后每30秒自动刷新

### 9. 添加进度更新接口

**文件**: `backend/task_queue.py`

- 新增 `update_task_progress()` 方法
- 支持在任务执行过程中更新进度百分比
- 在关键节点（25%, 50%, 75%, 100%）持久化到磁盘

## 测试验证

- 优先级队列：提交不同优先级的任务，验证高优先级任务先执行
- 取消任务：提交任务后取消，验证从等待列表正确移除
- 删除任务：删除已完成任务，验证文件和记录都被清理
- 重试任务：重试失败任务，验证新任务正确创建
- 批量提交：一次提交5个任务，验证全部入队
- 首页红点：提交任务后返回首页，验证红点显示正确数量
- 定时清理：验证清理后台任务正常启动
