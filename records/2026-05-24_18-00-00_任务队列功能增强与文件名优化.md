### 1. 任务列表页面的批量生成进度提示

### 2. 任务池并发执行（模型级并发）

**问题**: 原来的任务队列使用单一工作线程，所有任务串行执行，不同模型之间也无法并行。

**解决方案**:
- 实现模型级别的并发锁机制：不同模型可以并行执行，相同模型串行执行
- 新增 `_model_locks` 字典，为每个模型维护独立的 `asyncio.Lock`
- 工作线程使用 `asyncio.create_task()` 启动任务，不同模型的任务可以并行
- 相同模型的任务通过模型锁保证串行执行（避免GPU显存冲突）
- 队列状态API新增 `processing_models` 和 `concurrent_models` 字段

**修改文件**:
- `backend/task_queue.py`:
  - 新增 `_model_locks` 和 `_model_locks_lock`
  - 新增 `_get_model_lock()` 方法
  - 修改 `_worker_loop()` 使用 `asyncio.create_task()` 启动任务
  - 新增 `_execute_task_with_lock()` 方法
  - 更新 `get_queue_status()` 返回模型并发信息

### 4. 生成音频文件的命名更有意义

**问题**: 音频文件名只有模型名+时间戳（如 `voxcpm_20250524_120000.wav`），无法从文件名了解内容。

**解决方案**:
- 新增 `_generate_meaningful_filename()` 函数
- 文件名格式: `{model}_{mode}_{text摘要}_{timestamp}.wav`
- 批量生成时格式: `{model}_{mode}_{text摘要}_{timestamp}_{index}of{total}.wav`
- 文本摘要取前10个字符，移除文件名不友好字符
- 所有4个TTS任务处理器（VoxCPM/Qwen3-TTS/OmniVoice/CosyVoice）统一使用新命名

**修改文件**:
- `backend/task_handlers.py`:
  - 新增 `_generate_meaningful_filename()` 函数
  - 修改 `handle_voxcpm_task()` 使用新文件名
  - 修改 `handle_qwen3tts_task()` 使用新文件名
  - 修改 `handle_omnivoice_task()` 使用新文件名
  - 修改 `handle_cosyvoice_task()` 使用新文件名

## 修复: 批量生成进度始终显示 0%

**时间**: 2026-05-24 19:00:00

**问题**: 批量生成任务在任务列表中始终显示 `🔧 正在生成中 - 0%`，进度不更新。

**根因**: 
- 批量生成函数 `_batch_generate_voxcpm` / `_batch_generate_qwen3tts` 在线程池中执行（`run_in_executor`）
- 这些函数是同步函数，无法直接调用 asyncio 的进度更新方法
- 进度更新需要在主事件循环中执行，但线程池中的线程没有事件循环访问权限

**解决方案**:
- 新增 `ThreadSafeProgressUpdater` 类，提供线程安全的进度更新机制
- 使用 `asyncio.run_coroutine_threadsafe()` 将进度更新回调调度到主事件循环
- 批量生成函数增加 `progress_callback` 参数
- 任务处理器中定义回调函数，通过 `progress_updater.update_progress()` 线程安全地更新进度

**修改文件**:
- `backend/task_queue.py`:
  - 新增 `ThreadSafeProgressUpdater` 类
  - 在 `start()` 方法中设置事件循环
  - 全局导出 `progress_updater` 实例
- `backend/task_handlers.py`:
  - 导入 `progress_updater`
  - 在 `handle_voxcpm_task()` 和 `handle_qwen3tts_task()` 中定义 `_progress_callback`
  - 将回调传递给批量生成函数
- `backend/routers/batch.py`:
  - `_batch_generate_voxcpm()` 增加 `progress_callback` 参数
  - `_batch_generate_qwen3tts()` 增加 `progress_callback` 参数
  - 在每个音频生成前调用 `progress_callback(i, count)` 报告进度
  - 在完成后调用 `progress_callback(count, count)` 报告最终进度

## 技术要点

1. **模型级并发**: 使用 `asyncio.Lock` 为每个模型维护独立锁，通过 `asyncio.create_task()` 实现不同模型并行
2. **线程安全进度更新**: `ThreadSafeProgressUpdater` 使用 `asyncio.run_coroutine_threadsafe()` 将回调调度到主事件循环
3. **批量进度**: 在 `TaskRecord` 中增加批量字段，通过 `update_batch_progress()` 方法更新
4. **文件名生成**: 使用正则表达式清理文本摘要，确保文件名合法
5. **前端增量更新**: 保持原有增量更新逻辑，新增进度文本和标签的更新
