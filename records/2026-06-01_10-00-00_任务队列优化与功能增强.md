## 1. 修复批量生成进度提示问题

### 问题描述
当多个任务同时执行时，批量生成任务在任务列表页面缺少进度提示，用户无法直观了解批量任务的执行进度。

### 解决方案

#### 后端修改
- **文件**: `backend/task_handlers.py`
- **修改内容**: 在批量生成任务开始时设置 `batch_total` 和 `batch_completed` 字段
  - VoxCPM 批量任务处理器添加任务总数设置
  - Qwen3-TTS 批量任务处理器添加任务总数设置
  - OmniVoice 批量任务处理器添加任务总数设置
  - CosyVoice 批量任务处理器添加任务总数设置

#### 前端修改
- **文件**: `frontend/pages/tasks.html`
- **修改内容**:
  - 优化进度条显示，批量任务显示 "🎲 批量生成中 (X/Y) - Z%"
  - 等待中的批量任务显示 "⏳ 等待执行 - 批量生成 ×N"
  - 增量更新函数 `updateTaskCard` 支持批量进度实时更新

## 2. 任务池并发执行方案

### 问题描述
原有顺序队列无法充分利用系统资源，需要实现模型级并发控制，允许不同模型同时执行，同一模型串行执行。

### 解决方案

#### 新增 ModelState 类
- **文件**: `backend/task_queue.py`
- **功能**: 跟踪每个模型的状态
  - `is_busy`: 是否忙碌
  - `current_task_id`: 当前任务ID
  - `task_start_time`: 任务开始时间
  - `completed_count`: 完成任务数
  - `failed_count`: 失败任务数
  - `total_execution_time`: 总执行时间

#### 模型并发配置
```python
DEFAULT_MODEL_CONCURRENCY = {
    "voxcpm": 1,      # 本地GPU模型，串行执行
    "qwen3tts": 1,    # 本地GPU模型，串行执行
    "omnivoice": 2,   # 独立HTTP服务，可有限并行
    "cosyvoice": 2,   # 独立HTTP服务，可有限并行
}
```

#### 环境变量配置支持
- `MAX_CONCURRENT_VOXCPM`: VoxCPM 并发数
- `MAX_CONCURRENT_QWEN3TTS`: Qwen3-TTS 并发数
- `MAX_CONCURRENT_OMNIVOICE`: OmniVoice 并发数
- `MAX_CONCURRENT_COSYVOICE`: CosyVoice 并发数

#### 工作线程优化
- 修改 `_worker_loop` 方法，支持按模型并发限制派发任务
- 修改 `_execute_task` 方法，记录任务执行时长并更新模型状态
- 队列状态 API 返回模型状态信息

## 3. 优化任务列表页面信息展示

### 新增信息字段

#### 后端 API 增强
- **文件**: `backend/routers/task_queue.py`
- **新增字段**:
  - `wait_time_seconds`: 等待时长（秒）
  - `execution_time_seconds`: 执行时长（秒）

#### 前端展示优化
- **文件**: `frontend/pages/tasks.html`
- **新增样式**:
  - `.task-tag.time-tag`: 时间标签样式
  - `.task-tag.time-tag.waiting`: 等待中样式（橙色）
  - `.task-tag.time-tag.running`: 执行中样式（蓝色，带脉冲动画）
  - `.task-tag.time-tag.completed`: 已完成样式（绿色）
  - `.task-tag.time-tag.failed`: 失败样式（灰色）
  - `.task-time-detail`: 创建时间详情

#### 时间格式化函数
```javascript
function formatDuration(seconds) {
    // < 60秒: "X秒"
    // < 1小时: "X分Y秒" 或 "X分"
    // >= 1小时: "X时Y分" 或 "X时"
}
```

#### 任务卡片信息展示
- 等待中任务: "⏳ 等待 X秒/分/时"
- 执行中任务: "🔧 执行 X秒/分/时"
- 已完成任务: "✅ 执行 X秒 | 等待 Y秒"
- 失败/取消任务: "⏱️ 执行 X秒"

## 4. 优化音频文件命名规则

### 原有命名规则
```
{model}_{mode}_{text摘要}_{timestamp}.wav
```

### 新命名规则
```
{prefix}_{model}_{mode}_{speaker}_{text摘要}_{timestamp}_{batch}.wav
```

### 改进点
1. **添加说话人名称**: 使用克隆/预设音色时，文件名包含说话人名称
2. **批量生成序号**: 批量生成时显示 "01of10" 格式序号
3. **文本摘要优化**: 限制为8个字符，移除所有特殊字符
4. **前缀支持**: 支持添加自定义前缀（用于区分不同来源）

### 修改文件
- **文件**: `backend/task_handlers.py`
  - 更新 `_generate_meaningful_filename` 函数
  - VoxCPM 单音频生成传入说话人名称
  - Qwen3-TTS 单音频生成传入说话人名称

- **文件**: `backend/routers/batch.py`
  - VoxCPM 批量生成使用新命名规则
  - Qwen3-TTS 批量生成使用新命名规则

### 命名示例
```
# 单音频生成
voxcpm_clone_小明_你好世界_20250601_103045.wav
qwen3tts_custom_voice_vivian_今天天气_20250601_103102.wav

# 批量生成
voxcpm_clone_小明_你好世界_20250601_103045_01of05.wav
voxcpm_clone_小明_你好世界_20250601_103045_02of05.wav
qwen3tts_voice_clone_张三_欢迎使用_20250601_103102_01of10.wav
```
