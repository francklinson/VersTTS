# 修复独立服务批量生成进度更新问题

**时间**: 2026-06-01 22:00:00

**问题描述**:
当同时有两个模型（如 CosyVoice 和 Qwen3-TTS）在执行批量生成时，任务队列页面只显示一个模型的进度。从日志可以看到两个模型确实在并行执行，但前端进度条没有正确更新。

**根本原因**:
OmniVoice 和 CosyVoice 是独立 HTTP 服务，它们的批量生成函数 (`_batch_generate_omnivoice` 和 `_batch_generate_cosyvoice`) 没有接收进度回调函数参数，导致无法实时更新任务进度。

**解决方案**:

## 1. 修改 CosyVoice 批量生成函数

**文件**: `backend/routers/batch.py`

- 添加 `progress_callback` 参数
- 使用 `asyncio.as_completed` 替代 `asyncio.gather`，以便在任务完成时立即更新进度
- 每个任务完成后调用 `progress_callback(completed, count)`

```python
async def _batch_generate_cosyvoice(
    text: str, mode: str, count: int,
    speaker_id: str = None,
    control_prompt: str = None,
    progress_callback: Callable = None  # 新增
) -> Dict:
    # ...
    # 使用 as_completed 来实时获取结果并更新进度
    completed = 0
    for coro in asyncio.as_completed(pending_tasks):
        try:
            result = await coro
            if result.get("success"):
                audio_urls.append(result["audio_url"])
                audio_files.append(result["audio_file"])
            completed += 1
            # 报告进度
            if progress_callback:
                progress_callback(completed, count)
        except Exception as e:
            # ...
            if progress_callback:
                progress_callback(completed, count)
```

## 2. 修改 OmniVoice 批量生成函数

**文件**: `backend/routers/batch.py`

- 同样添加 `progress_callback` 参数
- 使用 `asyncio.as_completed` 实时更新进度

## 3. 更新任务处理器

**文件**: `backend/task_handlers.py`

### CosyVoice 任务处理器
- 导入 `progress_updater`
- 定义 `_progress_callback` 函数
- 调用 `_batch_generate_cosyvoice` 时传入 `progress_callback`

```python
from backend.task_queue import progress_updater

# 定义进度回调函数
def _progress_callback(completed: int, total: int):
    progress_updater.update_progress(
        task_queue.update_batch_progress,
        task.task_id, completed, total
    )

result = await _batch_generate_cosyvoice(
    # ...
    progress_callback=_progress_callback
)
```

### OmniVoice 任务处理器
- 同样添加进度回调支持

## 技术细节

### 为什么使用 `asyncio.as_completed`?

`asyncio.gather` 会等待所有任务完成后才返回，无法实时获取进度。

`asyncio.as_completed` 会在每个任务完成时立即返回结果，允许我们在任务完成时立即更新进度。

### 进度更新流程

1. 批量任务开始时，设置 `batch_total = count`, `batch_completed = 0`
2. 每个子任务完成时，调用 `progress_callback(completed, count)`
3. `progress_callback` 通过 `progress_updater` 线程安全地更新任务进度
4. 前端每 3 秒轮询任务列表，获取最新进度
