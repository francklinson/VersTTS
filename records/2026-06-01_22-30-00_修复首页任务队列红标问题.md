# 修复首页任务队列红标查看后不消失的问题

**时间**: 2026-06-01 22:30:00

**问题描述**:
首页任务队列的红点（badge）显示的是等待中和执行中的任务数量。当用户查看任务队列页面后，红点没有消失，因为红点显示的是实时任务状态，而不是"未读通知"。

**解决方案**:
实现一个"已查看"机制，使用 localStorage 记录用户已经查看过的活跃任务，首页红点只显示未查看的活跃任务。

## 实现细节

### 1. 任务队列页面 - 记录已查看的任务

**文件**: `frontend/pages/tasks.html`

- 在 `renderTasks` 函数后添加 `recordViewedTasks(tasks)` 调用
- 实现 `recordViewedTasks` 函数：
  - 获取当前状态为 `queued` 或 `processing` 的任务ID
  - 将这些任务ID添加到 localStorage 的 `versTTS_viewed_tasks` 列表
  - 清理已完成的任务ID（从已查看列表中移除）

```javascript
// 记录已查看的活跃任务（queued 或 processing 状态）
function recordViewedTasks(tasks) {
    const activeTaskIds = tasks
        .filter(t => t.status === 'queued' || t.status === 'processing')
        .map(t => t.task_id);

    let viewedTasks = JSON.parse(localStorage.getItem('versTTS_viewed_tasks') || '[]');

    // 添加当前活跃任务到已查看列表
    activeTaskIds.forEach(id => {
        if (!viewedTasks.includes(id)) {
            viewedTasks.push(id);
        }
    });

    // 清理已完成的任务ID
    const activeIdsSet = new Set(activeTaskIds);
    viewedTasks = viewedTasks.filter(id => activeIdsSet.has(id));

    localStorage.setItem('versTTS_viewed_tasks', JSON.stringify(viewedTasks));
}
```

### 2. 任务队列页面 - 页面加载时清理记录

**文件**: `frontend/pages/tasks.html`

- 添加 `cleanupViewedTasks` 函数，在页面初始化时执行
- 清理已完成的任务ID，只保留仍在活跃状态的任务

```javascript
// 清理已完成的查看记录（在页面加载时执行）
async function cleanupViewedTasks() {
    try {
        const response = await fetch(`${VersTTS.API_BASE}/tasks/list?limit=100`);
        if (response.ok) {
            const data = await response.json();
            if (data.success && data.tasks) {
                // 获取当前活跃的任务ID
                const activeTaskIds = data.tasks
                    .filter(t => t.status === 'queued' || t.status === 'processing')
                    .map(t => t.task_id);
                const activeSet = new Set(activeTaskIds);

                // 获取已记录的任务ID
                let viewedTasks = JSON.parse(localStorage.getItem('versTTS_viewed_tasks') || '[]');

                // 只保留仍在活跃状态的任务
                const cleanedTasks = viewedTasks.filter(id => activeSet.has(id));

                // 保存清理后的列表
                localStorage.setItem('versTTS_viewed_tasks', JSON.stringify(cleanedTasks));
            }
        }
    } catch (error) {
        console.log('清理查看记录失败:', error);
    }
}
```

## 工作流程

1. **用户提交任务**: 首页显示红点（新任务未查看）
2. **用户查看任务队列页面**:
   - 页面加载时清理已完成的任务记录
   - 渲染任务列表时记录当前活跃任务ID到 localStorage
3. **用户返回首页**: 红点只显示未查看的活跃任务
4. **任务完成**: 下次查看任务队列页面时，已完成的任务ID从记录中清理

4. 返回首页，红点应该消失
5. 提交另一个新任务
6. 首页应该再次显示红点（1）

## 总结

本次修复实现了任务队列红点的"已读"机制：
- 用户查看任务队列页面后，当前活跃任务被标记为"已查看"
- 首页红点只显示未查看的活跃任务
- 已完成的任务会自动从查看记录中清理
