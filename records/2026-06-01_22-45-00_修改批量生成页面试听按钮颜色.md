# 修改批量生成页面试听按钮颜色

**时间**: 2026-06-01 22:45:00

**问题描述**:
批量生成页面的试听按钮（audio 控件）显示为黑色，与页面整体蓝色主题不协调。

**解决方案**:
调整 CSS filter 参数，将试听按钮从黑色改为蓝色系。

## 修改内容

**文件**: `frontend/pages/tasks.html`

### 原样式
```css
.batch-audio-card audio {
    filter: invert(1) hue-rotate(200deg) saturate(1.5) brightness(1.1);
}
.batch-audio-card audio:hover {
    filter: invert(1) hue-rotate(210deg) saturate(1.8) brightness(1.2);
}
```

### 新样式
```css
.batch-audio-card audio {
    filter: invert(0.9) hue-rotate(185deg) saturate(2) brightness(1.15);
}
.batch-audio-card audio:hover {
    filter: invert(0.85) hue-rotate(185deg) saturate(2.2) brightness(1.25);
}
```

## 参数说明

- `invert(0.9)`: 降低反转程度（原来是 1，完全反转导致黑色）
- `hue-rotate(185deg)`: 调整色相为蓝色系
- `saturate(2)`: 增加饱和度，使颜色更鲜艳
- `brightness(1.15)`: 增加亮度，使按钮更明亮

## 效果

试听按钮现在显示为蓝色，与页面整体的蓝色主题（#667eea、#764ba2 渐变）更加协调。
