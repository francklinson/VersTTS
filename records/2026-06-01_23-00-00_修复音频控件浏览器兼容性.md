# 修复音频控件在不同浏览器上的样式差异

**时间**: 2026-06-01 23:00:00

**问题描述**:
批量生成页面的试听按钮（audio 控件）使用了 CSS filter 来调整颜色，但在 Chrome 和 Firefox 浏览器上的渲染效果不一致。

**解决方案**:
使用浏览器特定的伪元素来直接设置音频控件的样式，而不是依赖 filter。

## 修改内容

**文件**: `frontend/pages/tasks.html`

### 批量生成音频卡片

#### Chrome/Safari (WebKit)
```css
.batch-audio-card audio {
    width: 100%;
    height: 44px;
    border-radius: 22px;
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    border: 2px solid #667eea;
    outline: none;
}
.batch-audio-card audio::-webkit-media-controls-panel {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
.batch-audio-card audio::-webkit-media-controls-play-button {
    background-color: rgba(255, 255, 255, 0.9);
    border-radius: 50%;
}
.batch-audio-card audio::-webkit-media-controls-current-time-display,
.batch-audio-card audio::-webkit-media-controls-time-remaining-display {
    color: white;
    font-weight: 500;
}
```

#### Firefox
```css
.batch-audio-card audio::-moz-range-track {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    height: 8px;
    border-radius: 4px;
}
.batch-audio-card audio::-moz-range-thumb {
    background: white;
    border: 2px solid #667eea;
    border-radius: 50%;
    width: 16px;
    height: 16px;
}
```

### 单音频试听容器

同样为单音频试听控件添加了 Chrome 和 Firefox 的兼容样式，使用蓝色主题 (#0288d1)。

## 浏览器兼容性说明

### WebKit 浏览器 (Chrome, Safari, Edge)
使用 `::-webkit-media-controls-*` 伪元素：
- `::-webkit-media-controls-panel`: 控制面板背景
- `::-webkit-media-controls-play-button`: 播放按钮
- `::-webkit-media-controls-current-time-display`: 当前时间显示
- `::-webkit-media-controls-time-remaining-display`: 剩余时间显示

### Firefox
使用 `::-moz-range-*` 伪元素：
- `::-moz-range-track`: 进度条轨道
- `::-moz-range-thumb`: 进度条滑块

### 注意
由于浏览器的安全限制，音频控件的样式定制有一定局限性。Firefox 对音频控件的样式定制支持有限，上述样式可能无法完全覆盖所有控件元素。

## 测试建议

1. 在 Chrome 浏览器中检查批量生成结果的音频控件样式
2. 在 Firefox 浏览器中检查批量生成结果的音频控件样式
3. 检查单音频试听控件的样式
4. 验证播放按钮、进度条、时间显示等元素的颜色是否正确
