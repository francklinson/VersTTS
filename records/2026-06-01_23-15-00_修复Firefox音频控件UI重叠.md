# 修复 Firefox 浏览器音频控件 UI 重叠问题

**时间**: 2026-06-01 23:15:00

**问题描述**:
在 Firefox 浏览器中，批量生成页面的音频控件出现 UI 重叠问题。这是因为 Firefox 对 `audio` 控件的默认样式和高度处理与 Chrome 不同。

**解决方案**:
1. 使用 `@supports (-moz-appearance: none)` 为 Firefox 单独设置样式
2. 为 Chrome/Safari/Edge 使用 `min-height` 和 `max-height` 替代固定的 `height`
3. 增加卡片的最小高度和 flex 布局，确保音频控件有足够的空间

## 修改内容

**文件**: `frontend/pages/tasks.html`

### 1. 批量生成音频卡片样式

#### Chrome/Safari/Edge
```css
.batch-audio-card audio {
    width: 100%;
    min-height: 40px;
    max-height: 54px;
    border-radius: 20px;
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    border: none;
    outline: none;
    display: block;
    margin: 0;
    padding: 0;
}
```

#### Firefox 专用样式
```css
@supports (-moz-appearance: none) {
    .batch-audio-card audio {
        height: 54px;
        background: #f5f5f5;
        border: 1px solid #ddd;
        border-radius: 8px;
    }
}
```

### 2. 单音频试听样式

同样修改为使用 `min-height` 和 `max-height`，并为 Firefox 设置专用样式。

### 3. 卡片布局优化

```css
.batch-audio-card {
    min-height: 100px;
    display: flex;
    flex-direction: column;
    gap: 10px;
}
```

## 浏览器兼容性策略

### Chrome/Safari/Edge
- 使用 `min-height` 和 `max-height` 控制高度范围
- 使用 `::-webkit-media-controls-*` 伪元素自定义控件样式
- 保持蓝色渐变主题

### Firefox
- 使用 `@supports (-moz-appearance: none)` 检测 Firefox
- 设置固定高度 `height: 54px`
- 使用浏览器默认样式（浅灰色背景）
- 避免使用复杂的 filter 和渐变，减少兼容性问题

## 注意事项

1. Firefox 对音频控件的样式定制支持非常有限
2. 使用 `@supports` 可以精确针对 Firefox 设置样式
3. 保持 Chrome 的蓝色主题，Firefox 使用默认样式确保可用性

## 测试建议

1. 在 Firefox 中检查批量生成结果的音频控件是否还有重叠
2. 在 Chrome 中验证蓝色主题是否正常显示
3. 检查音频播放功能是否正常
