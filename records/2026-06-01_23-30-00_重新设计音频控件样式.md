# 重新设计音频控件样式

**时间**: 2026-06-01 23:30:00

**问题描述**:
音频控件在 Firefox 中显示为深色条，不够美观。需要重新设计一个更简洁、现代的外观。

**解决方案**:
采用浅色主题设计，使用简洁的灰白色背景和彩色播放按钮，使其在各种浏览器中都能保持良好的视觉效果。

## 修改内容

**文件**: `frontend/pages/tasks.html`

### 批量生成音频卡片

```css
.batch-audio-card audio {
    width: 100%;
    height: 36px;
    border-radius: 18px;
    background: #f8f9fa;
    border: 1px solid #e9ecef;
    outline: none;
    display: block;
    margin: 0;
    padding: 0;
    box-shadow: inset 0 1px 3px rgba(0,0,0,0.05);
}
/* Chrome/Safari/Edge */
.batch-audio-card audio::-webkit-media-controls-panel {
    background: transparent;
    border-radius: 18px;
    padding: 0 8px;
}
.batch-audio-card audio::-webkit-media-controls-play-button {
    background-color: #667eea;
    border-radius: 50%;
    width: 24px;
    height: 24px;
    filter: brightness(0) invert(1);
}
.batch-audio-card audio::-webkit-media-controls-current-time-display,
.batch-audio-card audio::-webkit-media-controls-time-remaining-display {
    color: #495057;
    font-weight: 500;
    font-size: 11px;
}
.batch-audio-card audio::-webkit-media-controls-timeline {
    margin: 0 6px;
    background: #dee2e6;
    border-radius: 3px;
    height: 4px;
}
.batch-audio-card audio::-webkit-media-controls-mute-button {
    filter: opacity(0.6);
}
/* Firefox */
@supports (-moz-appearance: none) {
    .batch-audio-card audio {
        background: #f8f9fa;
        border: 1px solid #e9ecef;
    }
}
```

### 单音频试听

同样采用浅色主题设计，使用蓝色播放按钮 (#0288d1)。

## 设计特点

1. **浅色背景**: 使用 `#f8f9fa` 浅灰色背景，更清爽
2. **细边框**: 使用 `#e9ecef` 边框，增加层次感
3. **彩色播放按钮**: 
   - 批量生成：紫色 (#667eea)
   - 单音频试听：蓝色 (#0288d1)
4. **内阴影**: 添加轻微内阴影，增加立体感
5. **统一高度**: 批量生成 36px，单音频试听 40px
6. **圆角设计**: 保持圆角风格，与页面整体协调

## 浏览器兼容性

- **Chrome/Safari/Edge**: 完全支持自定义样式
- **Firefox**: 使用默认样式，但保持相同的浅色主题

## 视觉效果

- 播放按钮：白色图标，彩色背景
- 时间显示：深灰色文字 (#495057)
- 进度条：浅灰色背景 (#dee2e6)
- 静音按钮：半透明效果

## 测试建议

1. 在 Chrome 中检查音频控件的浅色主题效果
2. 在 Firefox 中检查音频控件的显示效果
3. 验证播放按钮的颜色是否正确
4. 检查时间显示和进度条的样式
