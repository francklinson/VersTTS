# 修复 Chrome 浏览器试听控件变白问题

**时间**: 2026-06-01 23:45:00

**问题描述**:
在 Chrome 浏览器中，试听控件的播放按钮使用了 `filter: brightness(0) invert(1)`，这会把按钮颜色反转成白色。但由于背景也是浅色，导致按钮看不清。

**解决方案**:
移除 `filter: brightness(0) invert(1)`，让播放按钮保持彩色背景（紫色/蓝色），这样按钮就能正常显示了。

## 修改内容

**文件**: `frontend/pages/tasks.html`

### 批量生成音频卡片

```css
/* 修改前 */
.batch-audio-card audio::-webkit-media-controls-play-button {
    background-color: #667eea;
    border-radius: 50%;
    width: 24px;
    height: 24px;
    filter: brightness(0) invert(1);  /* 这行导致按钮变白 */
}

/* 修改后 */
.batch-audio-card audio::-webkit-media-controls-play-button {
    background-color: #667eea;
    border-radius: 50%;
    width: 24px;
    height: 24px;
}
```

### 单音频试听

同样移除 `filter: brightness(0) invert(1)`。

## 效果

- 播放按钮现在显示为彩色圆形（紫色/蓝色）
- 按钮在浅色背景上清晰可见
- 与页面整体风格协调

## 测试建议

1. 在 Chrome 中检查播放按钮是否正常显示
2. 验证播放按钮的颜色是否正确（紫色/蓝色）
3. 检查 Firefox 中是否也正常显示
