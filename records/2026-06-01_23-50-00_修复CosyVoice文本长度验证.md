# 修复 CosyVoice 批量生成因文本太短导致的错误

**时间**: 2026-06-01 23:50:00

**问题描述**:
CosyVoice 批量生成时出现错误：`RuntimeError: Calculated padded input size per channel: (3). Kernel size: (4). Kernel size can't be greater than actual input size`。这是因为输入文本太短（少于3个字符），导致模型无法处理。

**解决方案**:
在 CosyVoice 任务处理前添加文本长度验证，确保文本至少有3个字符。

```python
        raise ValueError(f"CosyVoice 需要至少3个字符的文本，当前只有 {len(text.strip())} 个字符")
    
    # ... 后续代码
```

**文件**: `backend/task_handlers.py`

## 效果

- 当用户提交少于3个字符的文本时，任务会立即失败并返回清晰的错误信息
- 避免调用 CosyVoice 服务后出现难以理解的 RuntimeError
- 提高用户体验，明确告知文本长度要求
