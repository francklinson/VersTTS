## 三、代码修改清单

### 1. `backend/config.py`
```python

# 修改后

```

### 2. `pilottts_service.py` (独立服务)
```python

# 修改后
PRETRAINED_DIR = os.path.join(PROJECT_ROOT, "models", "PilotTTS")
```

同时修复了 campplus 路径解析逻辑 — 对 `pretrained_models/` 前缀的路径使用 `PRETRAINED_DIR` 而非 `PILOTTS_DIR` 作为基路径。

### 3. `backend/engines/pilottts_engine.py` (本地引擎)
- 新增 `PROJECT_ROOT` 导入
- 备用路径从 `os.path.join(pilottts_dir, 'pretrained_models')` 改为 `os.path.join(PROJECT_ROOT, 'models', 'PilotTTS')`
- 同步修复 campplus 路径解析逻辑
