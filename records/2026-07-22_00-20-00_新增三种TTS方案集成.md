## 二、dots.tts 集成

### 方案概要
- **仓库**: `rednote-hilab/dots.tts` (小红书开源)
- **架构**: Continuous AR + Flow-Matching (Qwen2.5-1.5B), 2B 参数
- **许可证**: Apache-2.0（可商用）
- **模型大小**: ~5.2GB (soar 变体)
- **部署模式**: 本地 GPU 模型（engine + route）

### 创建文件
| 文件 | 说明 |
|------|------|
| `backend/engines/dotstts_engine.py` | 模型加载器，支持 OOM 驱逐重试 |
| `backend/routers/tts/dotstts.py` | API 路由，POST /tts/dotstts |
| `frontend/pages/dotstts.html` | 前端页面，紫色主题 |

### 支持功能
- **voice_clone**: 零样本声音克隆（需选说话人）
- **instruct**: 指令 TTS（音色描述模式）
- 参数: num_steps (4-32), guidance_scale (1.0-5.0), speaker_scale (0.5-2.0)
- 输出: 48kHz 高保真音频
- 24 种语言 + 粤语

### 配置更新
- `backend/config.py`: 添加 MODEL_PATHS['dotstts']、ALGORITHM_PATHS['dotstts']/['dotstts_src']
- `backend/engines/__init__.py`: 导出 `get_dotstts_model`
- `backend/routers/tts/__init__.py`: 注册 `/dotstts` 前缀
- `backend/task_handlers.py`: 添加 `handle_dotstts_task()`
- `backend/task_queue.py`: 添加 `"dotstts": 1` 并发
- `frontend/index.html`: 添加模型卡片

### 待办

## 三、Fish-Speech 集成

### 方案概要
- **仓库**: `fishaudio/fish-speech`
- **架构**: Dual-AR (Slow 4B + Fast 400M), Qwen3 骨干, ModifiedDAC
- **许可证**: 仅限研究/非商业使用
- **模型大小**: ~11GB (INT8 ~5.1GB)
- **部署模式**: 独立 HTTP 服务（端口 8005）

### 创建文件
| 文件 | 说明 |
|------|------|
| `fishspeech_service.py` | 独立 FastAPI 服务，端口 8005 |
| `backend/routers/tts/fishspeech.py` | 转发路由，POST /tts/fishspeech |
| `frontend/pages/fishspeech.html` | 前端页面，海蓝色主题 |

### 支持功能
- **voice_clone**: 零样本声音克隆（需选说话人）
- **voice_design**: 声音设计（自然语言描述音色）
- 参数: temperature (0.1-1.5), top_p (0.5-1.0), repetition_penalty (1.0-1.5)
- 内联情感标签: [laugh], [sad], [excited], [angry], [whisper], [sigh]
- 输出: 44.1kHz 音频
- 80+ 种语言

### start_server.sh 更新
- 添加 Fish-Speech 服务管理: start-fishspeech, stop-fishspeech, restart-fishspeech, status-fishspeech
- 集成到 do_start/do_stop/do_restart/do_status 主流程
- GPU 配置: FISHSPEECH_GPU

### 配置更新
- `backend/config.py`: 添加 FISHSPEECH_HOST/PORT、MODEL_PATHS、ALGORITHM_PATHS
- `backend/routers/tts/__init__.py`: 注册 `/fishspeech` 前缀
- `backend/task_handlers.py`: 添加 `handle_fishspeech_task()`
- `backend/task_queue.py`: 添加 `"fishspeech": 2` 并发
- `frontend/index.html`: 添加模型卡片

### 待办
