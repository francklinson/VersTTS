# =============================================================================
# 重要说明：独立服务依赖
# =============================================================================
#
# 由于不同 TTS 算法依赖不同版本的 transformers，以下算法使用独立服务：
#
# 1. OmniVoice (端口 8001)
#    - 依赖: lib/transformers5/
#    - transformers 版本: 5.x
#    - 不需要在主环境安装
#
# 2. CosyVoice (端口 8002)
#    - 依赖: lib/transformers4/
#    - transformers 版本: 4.51.3
#    - 不需要在主环境安装
#
# 主服务使用 transformers 4.57.3，支持 Qwen3-TTS、VoxCPM 等算法
#
# 独立服务启动命令:
#   ./start_server.sh start-omnivoice    # 启动 OmniVoice 服务
#   ./start_server.sh start-cosyvoice    # 启动 CosyVoice 服务
#   ./start_server.sh start-all          # 启动所有服务
# =============================================================================
